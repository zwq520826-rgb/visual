# Q5 行业动态趋势：现有数据与字段说明

Q5 当前分两部分：
- 职位综合排名（TopN）
- 行业双环玫瑰/星云分析

## 1. Q5 当前可用接口

- `GET /api/industry/ranking/jobs`
  - 返回职位综合得分 TopN（当前默认 Top5）
- `GET /api/industry/trend/rose`
  - 返回行业趋势玫瑰图主数据

对应代码：`routes/industry_routes.py`、`services/trend_service.py`

---

## 2. Q5 关键数据表

## 2.1 `job_summary`（职位排名源表）

| 字段 | 类型 | 含义 | Q5 用途 |
|---|---|---|---|
| `job_title` | varchar | 职位 | 维度主键 |
| `records_count` | bigint | 样本量 | 规模参考 |
| `records_count_norm` | double | 归一化样本量 | 综合得分因子 |
| `avg_education_rank` | double | 平均学历分值 | 综合得分因子 |
| `avg_experience_rank` | double | 平均经验分值 | 综合得分因子 |
| `median_salary` 等薪资字段 | double | 薪资统计 | 扩展维度 |
| `company_type` | varchar | 行业编码 | 扩展维度 |
| `total_shannon_entropy` | double | 分布熵 | 扩展维度 |

## 2.2 `national_industry_stats`（行业趋势源表）

| 字段 | 类型 | 含义 | Q5 用途 |
|---|---|---|---|
| `company_type` | varchar | 行业编码 | 行业维度 |
| `job_count` | bigint | 岗位总量 | 规模参考 |
| `avg_median_salary` | double | 行业平均中位薪资 | 玫瑰图内环/色彩 |
| `avg_experience_rank` | decimal | 经验均值 | 外环分层 |
| `avg_education_rank` | decimal | 学历均值 | 外环分层 |
| `city_count` | bigint | 覆盖城市数 | 扩展维度 |
| `job_type_count` | bigint | 职位类型数 | 扩展维度 |

说明：服务层对经验/学历做了尺度识别（0-10 或 0-1）与归一化，避免不同数据口径混用。

---

## 3. 字段计算口径（服务层）

## 3.1 职位综合排名（`/industry/ranking/jobs`）

`TrendService.get_job_ranking()` 核心公式：

- `education_norm = avg_education_rank / 10`
- `experience_norm = avg_experience_rank / 10`
- `composite_score = education_norm * records_count_norm * experience_norm`

返回字段：

- `job_title`
- `records_count_norm`
- `education_rank`（归一化后）
- `experience_rank`（归一化后）
- `composite_score`

## 3.2 行业趋势玫瑰（`/industry/trend/rose`）

返回字段（每个行业）：

- `company_type`, `industry_name`
- `national_job_count`
- `avg_median_salary`
- `avg_experience_rank`, `avg_education_rank`（0-1用于图）
- `avg_experience_rank_10`, `avg_education_rank_10`（原始10分制）
- `avg_experience_rank_normalized`, `avg_education_rank_normalized`
- `outer_ring_bucket`, `outer_ring_color`, `outer_ring_norm`

## 4. Q5 设计建议

- 排名视图可突出 `composite_score` 分解（经验/学历/规模贡献）；
- 玫瑰图建议分层编码：
  - 内环：行业规模或薪资
  - 外环：经验/学历门槛
- 对 `company_type` 建议做可读名映射，避免直接显示编码字符串。
