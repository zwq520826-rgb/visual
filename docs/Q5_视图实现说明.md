# Q5 视图实现说明

## 1. 任务定位

Q5 当前页面对应“行业引力网络”。与历史方案中的多页多视图设计不同，当前实现已经收敛为单页主视图：围绕“新兴岗位与行业节点的关联结构”展开，通过岗位卡、过滤控制、KPI 摘要和引力网络主画布，回答“哪些岗位是核心枢纽、覆盖了哪些行业、行业关联的强弱和层次如何”。

当前页面入口为 `fronted/src/components/tabs/Q5Tab.vue`。

## 2. 页面总览

- 页面结构简化为一张核心工作台。
- 顶部是标题和说明。
- 中部依次是：
  - 新兴岗位卡片区
  - 过滤/对比控制区
  - 对比岗位面板（按需显示）
  - KPI 摘要区
  - 引力网络主画布
- 当前 Q5 不再存在旧文档中的“两页式切换”“玫瑰图”“星云图”等已下线结构。

## 3. 页面控制与核心状态

- 核心状态包括：
  - `forceTier`
  - `forceTopKIndustry`
  - `activeForceJobTitle`
  - `hideOtherForceGraphs`
  - `selectedContrastJobTitle`
- 页面会并行准备三类数据：
  - 新兴岗位列表
  - 排名岗位列表
  - 对比岗位兜底列表
- 岗位网络本身被缓存到：
  - `forceNetworkByJob`
  - `contrastNetworkByJob`

## 4. 视图 A：新兴岗位卡片区

### 4.1 位置与职责

- 位置：主图上方第一层。
- 职责：展示前 5 个新兴岗位，并作为引力网络的主切换入口。

### 4.2 视觉与编码方式

- 使用卡片按钮网格布局。
- 每张卡片包含：
  - 排名序号
  - 岗位标题
  - 需求量
  - 学历门槛
  - 经验门槛
- 当前激活卡片会带有 `active` 样式。

### 4.3 数据与字段

- 数据来自 `getQ5ForceEmergingJobs(topN)`，接口路径为 `/q5/force/emerging-jobs`。
- 主要字段包括：
  - `job_title`
  - `records_count`
  - `education_label`
  - `experience_label`
  - `composite_score`

### 4.4 数据流

- 页面初始化时通过 `executeForceJobs(5)` 请求前 5 个新兴岗位。
- 第一个岗位默认会成为 `activeForceJobTitle`。

### 4.5 交互与联动

- 点击岗位卡会调用 `selectForceJob(jobTitle)`。
- 激活岗位改变后，主网络图和 KPI 区会同步切换到对应岗位。

### 4.6 状态与限制

- 若岗位列表请求失败，会显示 `forceJobsError`。
- 加载期间显示“正在加载前5新兴职业...”。

### 4.7 实现备注

- 该区域不是独立图表组件，而是 `Q5Tab.vue` 内部直接渲染的状态卡片区。

## 5. 视图 B：过滤与对比控制区

### 5.1 位置与职责

- 位置：岗位卡片区下方。
- 职责：控制当前网络的城市层级、行业节点数量和是否进入岗位对比模式。

### 5.2 视觉与编码方式

- 当前控制项包括：
  - 城市等级下拉
  - 行业节点上限滑杆
  - “显示其他引力图”开关
- 开关右侧会显示模式说明：
  - 全景模式
  - 对比模式

### 5.3 数据与字段

- 城市等级传给接口字段 `tier`。
- 行业节点上限传给接口字段 `top_k_industry`。

### 5.4 数据流

- 当 `forceTier` 或 `forceTopKIndustry` 变化时，页面会重新加载岗位网络。
- 当对比模式开启时，会额外准备对比岗位和对比岗位网络。

### 5.5 交互与联动

- 所有控制都直接作用于网络视图，而不是本地纯样式切换。
- 对比模式开启后，下方会出现“对比岗位（非新兴）”面板。

### 5.6 状态与限制

- 当前行业节点上限滑杆范围是 `10-15`。
- 城市等级支持 `all / first_tier / second_tier / third_tier / other`。

### 5.7 实现备注

- 控制逻辑写在 `Q5Tab.vue`，没有拆成独立控制组件。

## 6. 视图 C：对比岗位面板

### 6.1 位置与职责

- 位置：仅在对比模式开启时显示，位于控制区下方。
- 职责：从非新兴岗位中挑出 1 个对比对象，与当前激活的新兴岗位并列展示网络。

### 6.2 视觉与编码方式

- 使用 `chip` 式按钮列表。
- 每个按钮展示：
  - 岗位名称
  - 伪规模或记录数
  - 对比标签

### 6.3 数据与字段

- 主要数据来源有两层：
  - `getJobRanking()`：排名接口主来源
  - `getQ5ForceContrastJobs()`：兜底来源
- 前端会基于规模、门槛和综合分做轻量多样性挑选，并生成：
  - `高规模普及型`
  - `高门槛型`
  - `低综合稳态型`
  - `常规对比型`

### 6.4 数据流

- 开启对比模式后，若还没有对比列表，页面会先请求对比来源。
- 选中对比岗位后，再调用 `getQ5ForceJobNetwork(jobTitle, topKIndustry, tier)` 请求其网络。

### 6.5 交互与联动

- 点击某个对比岗位后，主画布会同时显示当前新兴岗位网络和该对比岗位网络。

### 6.6 状态与限制

- 该面板只在 `hideOtherForceGraphs === true` 时显示。
- 排名来源不足时，自动退回到兜底接口。

### 6.7 实现备注

- 这部分是 `Q5Tab.vue` 中最明显的前端数据加工逻辑之一，不是后端直接给定的最终对比列表。

## 7. 视图 D：KPI 摘要区

### 7.1 位置与职责

- 位置：网络画布上方、对比面板下方。
- 职责：对当前激活网络做快速指标摘要。

### 7.2 视觉与编码方式

- 使用网格型 KPI 卡片。
- 当前展示 6 个指标：
  - 核心岗位
  - 岗位需求量
  - 行业覆盖度
  - 核心/星尘
  - 破壁熵
  - 枢纽分

### 7.3 数据与字段

- 这些指标全部来自 `activeForceNetwork.summary`。
- 实际读取的核心字段包括：
  - `job_total_count`
  - `industry_degree`
  - `industry_degree_core`
  - `industry_degree_dust`
  - `industry_entropy`
  - `hub_score`

### 7.4 数据流

- 只要 `activeForceNetwork` 更新，KPI 就同步更新。
- 若当前没有激活网络或 summary 缺失，KPI 区不会渲染。

### 7.5 交互与联动

- KPI 本身不触发联动，承担解释型摘要作用。

### 7.6 状态与限制

- KPI 区依赖网络详情返回的 `summary` 字段，不能独立显示。

### 7.7 实现备注

- 该区域同样是在 `Q5Tab.vue` 内直接组织，没有独立封装组件。

## 8. 视图 E：引力网络主视图

### 8.1 位置与职责

- 位置：页面底部主体区域，占据最大空间。
- 职责：将岗位与行业的引力关系以网络形式展示，是 Q5 的核心分析画布。

### 8.2 视觉与编码方式

- 使用 ECharts `graph` 系列，自定义布局为多岗位长卷式网络。
- 每个岗位簇包含：
  - 一个岗位中心节点
  - 一圈核心行业节点
  - 一组星尘行业节点
- 连线颜色按薪资高低从冷蓝映射到暖红。
- 当前激活岗位簇会强化中心节点、标签和核心连线的可见性。

### 8.3 数据与字段

- 网络数据来源于 `getQ5ForceJobNetwork(jobTitle, topKIndustry, tier)`，接口路径为 `/q5/force/job-network`。
- 主图读取的核心结构包括：
  - `nodes`
  - `links`
  - `summary`
  - `job_title`
- 节点会区分 `type === 'job'` 和 `type === 'industry'`。
- 连线会区分 `edge_class === 'core'` 与 `edge_class === 'dust'`。

### 8.4 数据流

- 页面在加载新兴岗位后，会并行请求每个岗位的网络，保存到 `forceNetworkByJob`。
- `displayedForceNetworks` 负责决定主画布到底显示：
  - 全部新兴岗位网络
  - 当前新兴岗位 + 一个对比岗位网络
- `Q5ForceAtlasGraph` 会根据 `activeJobTitle` 自动把激活岗位中心移到视口中间。

### 8.5 交互与联动

- 主图支持漫游、缩放和邻接高亮。
- 核心行业连线增加了“不可见命中层”，提高 hover 命中灵敏度。
- 图的主联动入口不是点击节点，而是由上方岗位卡和对比面板控制显示集合。

### 8.6 状态与限制

- 加载网络时显示“正在加载引力图...”。
- 如果 `networks` 为空，显示“暂无网络数据”。
- 如果渲染阶段抛错，会显示 `renderError`。

### 8.7 实现备注

- 组件路径：`fronted/src/components/charts/Q5ForceAtlasGraph.vue`
- 当前组件仍保留“多岗位长卷画布”实现，不是单岗位静态力导图。
- 星尘行业节点和核心行业节点在布局和交互强度上有明显区分。

## 9. 联动与状态流

- 新兴岗位卡切换 -> 更新 `activeForceJobTitle` -> 切换 KPI 与网络中心簇。
- 城市等级/行业节点数变化 -> 重新加载岗位网络 -> 刷新整张引力图。
- 对比模式开启 -> 生成对比岗位列表 -> 请求对比岗位网络 -> 和当前新兴岗位并列展示。

## 10. 实现落点

- 页面入口：`fronted/src/components/tabs/Q5Tab.vue`
- 核心图组件：`fronted/src/components/charts/Q5ForceAtlasGraph.vue`
- API 文件：`fronted/src/api/industryApi.js`
