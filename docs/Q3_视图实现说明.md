# Q3 视图实现说明

## 1. 任务定位

Q3 当前页面对应“薪资多维分析”。页面围绕经验、学历、薪资分布和职位薪酬模式分群，形成“单点组合观察 + 条件分布分析 + 聚类模式识别”的三层分析链。

当前页面入口为 `fronted/src/components/tabs/Q3Tab.vue`。页面在挂载时并行请求三维薪资数据和聚类数据，并把两个数据流分别交给上半区和下半区的视图体系。

## 2. 页面总览

- 页面结构分为上下两层。
- 上层左右并排：
  - 左侧是三维柱状对比图。
  - 右侧是箱线图分析。
- 下层是一整块“聚类双视图容器”，内部再拆成散点聚类图和平行坐标图。
- 页面还提供一个显式按钮，用于开启或关闭手势摄像头。

## 3. 页面控制与核心状态

- 页面核心状态包括：
  - `selectedExperience`
  - `selectedEducation`
  - `gestureEnabled`
- 上层联动由 3D 柱图触发，点击柱体后把经验和学历写入状态，再传给箱线图。
- 下层聚类视图的数据刷新通过 `Q3DualModeViews` 发出的 `reload` 事件回到 `Q3Tab`，由父组件重新请求接口。
- 页面首次加载时，聚类接口默认使用 `nClusters=5`、`algorithm='kmeans'`、`sampleSize=12000`。

## 4. 视图 A：三维柱状对比图

### 4.1 位置与职责

- 位置：页面上层左侧。
- 职责：展示经验 × 学历 × 薪资三维关系，并作为箱线图筛选条件的交互入口。

### 4.2 视觉与编码方式

- 使用三维柱状编码。
- 三个维度分别映射到经验、学历和薪资。
- 页面在图表上方提供“开启/关闭手势摄像头”的按钮，用于扩展视角控制方式。

### 4.3 数据与字段

- 数据来自 `get3DSalaryData()`，接口路径为 `/charts/3d/experience-education-salary`。
- 该视图主要关心三个字段维度：
  - 经验分组
  - 学历分组
  - 薪资统计值

### 4.4 数据流

- `Q3Tab` 挂载时执行 `execute()` 请求三维薪资数据。
- 数据通过 `chartData?.data` 传入 `Chart3D`。
- `Chart3D` 点击事件会把当前柱体的经验和学历返回给父组件。

### 4.5 交互与联动

- 点击柱体会触发 `@bar-click="handleBarClick"`。
- `handleBarClick` 会更新 `selectedExperience` 与 `selectedEducation`，进而驱动右侧箱线图重新请求或重算。
- 手势开关通过 `gestureEnabled` 传入子组件，用于控制手势相关功能是否启用。

### 4.6 状态与限制

- 若数据尚未返回，由父层 `loading` 控制加载态。
- 手势能力是附加交互，不影响图表主分析流程。
- 页面没有额外条件筛选，3D 图默认先展示全局数据。

### 4.7 实现备注

- 组件路径：`fronted/src/components/charts/Chart3D.vue`
- API 文件：`fronted/src/api/salary3dApi.js`
- 该图在当前实现中不仅是展示图，也是上层联动的唯一条件输入源。

## 5. 视图 B：箱线图分析

### 5.1 位置与职责

- 位置：页面上层右侧。
- 职责：在经验和学历条件下观察薪资分布、离散程度和异常值。

### 5.2 视觉与编码方式

- 使用箱线图表达薪资分布。
- 页面标题固定为“箱线图分析”，是 Q3 中承接细分条件的统计分布视图。

### 5.3 数据与字段

- 数据来源对应 `getBoxplotData(filters)`，接口路径为 `/charts/boxplot/salary-distribution`。
- 当前父组件直接传入两个核心筛选条件：
  - `experience`
  - `education`
- API 还支持 `city` 和 `company_type`，说明箱线图组件内部可继续做二级筛选。

### 5.4 数据流

- `BoxplotChart` 接收父层的 `selectedExperience` 与 `selectedEducation`。
- 当上游 3D 图点击改变这两个值时，箱线图切换到新的条件上下文。

### 5.5 交互与联动

- 与 3D 图形成单向联动关系。
- 箱线图本身主要承担分布解释，不反向控制其他视图。

### 5.6 状态与限制

- 如果上游还未选择经验/学历组合，箱线图会以默认或空筛选状态展示。
- 该视图的解释力高度依赖 3D 图传入的上下文，因此更偏“条件细看”而非“全局总览”。

### 5.7 实现备注

- 组件路径：`fronted/src/components/charts/BoxplotChart.vue`
- API 文件：`fronted/src/api/salary3dApi.js`

## 6. 视图 C：薪酬模式聚类分布图

### 6.1 位置与职责

- 位置：页面下层双视图容器左侧，由 `Q3DualModeViews` 内部渲染。
- 职责：展示职位在聚类空间中的分群结构，并作为下层联动的主选择入口。

### 6.2 视觉与编码方式

- 使用二维散点图显示聚类点位。
- 颜色按 `cluster_id` 分簇着色。
- 图例支持点击簇项进行高亮或筛选。
- 面板头部显示坐标模式、显示点数和图形类型说明。

### 6.3 数据与字段

- 数据来自 `getSalaryClusters()`，接口路径为 `/charts/salary-clusters`。
- 视图直接使用的核心数据结构包括：
  - `points`
  - `cluster_summary`
  - `metadata`
  - `parallel_payload`
- 单点对象中会读取：
  - `point_id`
  - `cluster_id`
  - `job_title`
  - `company_type`
  - `features.median_salary`
  - `cluster_inputs.salary_index`
  - `cluster_inputs.barrier_index`

### 6.4 数据流

- 父组件请求聚类数据后，通过 `clusterData?.data` 整体传入 `Q3DualModeViews`。
- 子组件根据 `coordMode`、`contourMode` 等内部状态决定散点图具体呈现方式。

### 6.5 交互与联动

- 点击图例可切换激活簇。
- 散点图框选后，会把选中的点位集合同步给右侧平行坐标，用于高亮对应折线。
- 选中单点时，底部洞察卡会显示当前点位的职位、簇标签和薪资信息。

### 6.6 状态与限制

- 当 `points.length === 0` 时显示“暂无可用聚类数据”。
- 当渲染过程异常时，显示 `renderError`。
- 聚类图和右侧平行坐标共享同一份聚类数据，因此任何刷新都会同时影响两个视图。

### 6.7 实现备注

- 组件路径：`fronted/src/components/charts/Q3DualModeViews.vue`
- 当前实现中，簇语义标签如“高薪高门槛型”“低薪低门槛型”等是在前端根据 `cluster_id` 做的显示映射。

## 7. 视图 D：多维特征关联平行坐标系

### 7.1 位置与职责

- 位置：页面下层双视图容器右侧。
- 职责：把聚类散点中的点位展开为多维属性线条，用于查看聚类内部的特征结构。

### 7.2 视觉与编码方式

- 使用平行坐标图。
- 面板头部显示当前模式标签与可见线条数。
- 支持 `centroid` 与 `sampled` 两类并行模式：
  - `centroid` 更偏质心摘要
  - `sampled` 更偏样本线条展示

### 7.3 数据与字段

- 数据并不是单独请求，而是复用聚类接口返回的 `parallel_payload`。
- 组件会读取：
  - `parallel_payload.axis_meta`
  - `parallel_payload.centroid_lines`
  - `parallel_payload.sampled_lines`

### 7.4 数据流

- `parallelRows` 会根据 `parallelMode` 从 `centroid_lines` 或 `sampled_lines` 中择一。
- 在 `sampled` 模式下，组件会限制可见线数，避免过载。

### 7.5 交互与联动

- 在平行坐标轴上刷选区间后，满足条件的点位会反向高亮到左侧散点图。
- 组件底部的两张洞察卡会实时总结：
  - `Scatter -> Parallel`
  - `Parallel -> Scatter`

### 7.6 状态与限制

- 平行坐标不独立存在，它完全依赖聚类接口返回的数据。
- 当聚类结果为空时，下层两张图同时进入空态。

### 7.7 实现备注

- 组件路径仍是 `fronted/src/components/charts/Q3DualModeViews.vue`
- 该平行坐标不是独立 Tab，而是聚类容器内部的第二视图。

## 8. 联动与状态流

- 上层链路：`3D 柱图点击 -> selectedExperience / selectedEducation -> 箱线图`
- 下层链路：`聚类散点选择 <-> 平行坐标刷选`
- 重新加载链路：`Q3DualModeViews.emit('reload') -> Q3Tab.handleClusterReload -> getSalaryClusters()`

## 9. 实现落点

  - `fronted/src/components/charts/Q3DualModeViews.vue`
