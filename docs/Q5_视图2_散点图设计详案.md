# 视图2：新兴职位识别散点图 - 完整设计方案

## 一、设计概述

### 目标定位
通过**二维散点图**直观展示职位的**经济价值**与**人才稀缺度**的关系，快速识别"高薪资+高稀缺+强需求"的**新兴职位集合**，为求职者、企业、教育机构提供人才决策参考。

### 核心问题
- 哪些职位属于"新兴"且值得关注？
- 职位的经济吸引力与人才缺口是否匹配？
- 新兴职位有什么共同特征？

## 三、数据编码方案

### 3.1 四维编码

| 维度 | 编码方式 | 数据源 | 值域范围 |
|---|---|---|---|
| **X轴** | 水平位置 | `job_summary.median_salary` | 10 ~ 50 万元 |
| **Y轴** | 竖直位置 | **稀缺度指数**（衍生） | 30 ~ 100 分 |
| **气泡大小** | 面积大小 | `job_summary.records_count_norm` | 0.1 ~ 1.0 |
| **气泡颜色** | 色彩 | `job_summary.company_type`（行业） | 158 种分类 |

### 3.2 稀缺度指数计算

#### 定义
```
稀缺度指数 = 技能门槛指数 × 0.7 + 供给缺口指数 × 0.3

其中：
  技能门槛指数 = (平均教育等级 + 平均经验等级) / 2
  供给缺口指数 = 1 - 岗位供给占比
```

#### 计算步骤
```python
# 步骤1：获取基础数据
education_rank = avg_education_rank / 10  # 转换到0-1范围
experience_rank = avg_experience_rank / 10
supply_ratio = records_count_norm  # 已是0-1

# 步骤2：计算两个子指数
skill_threshold = (education_rank + experience_rank) / 2
supply_shortage = 1 - supply_ratio

# 步骤3：综合计算稀缺度
scarcity_index = (skill_threshold * 0.7 + supply_shortage * 0.3) * 100

# 最终范围：0 ~ 100
```

#### 计算示例
```
职位A：云计算架构师
  - avg_education_rank = 7.5 (满分10)
  - avg_experience_rank = 6.0 (满分10)
  - records_count_norm = 0.15 (岗位供给占比较低)
  
  可算值：
  skill_threshold = (7.5/10 + 6.0/10) / 2 = 0.675
  supply_shortage = 1 - 0.15 = 0.85
  scarcity_index = (0.675 * 0.7 + 0.85 * 0.3) * 100
                 = (0.4725 + 0.255) * 100
                 = 72.75 ≈ 73分
  
  解释：云计算架构师属于"高稀缺职位"
```

### 3.3 气泡大小映射

#### 映射公式
```
气泡半径 = sqrt(records_count_norm) × 基础半径 + 最小半径

基础半径 = 30 (像素)
最小半径 = 8 (像素)
```

#### 大小等级
| 岗位量占比 | 气泡半径 | 视觉参考 | 含义 |
|---|---|---|---|
| 0-0.2% | 8-15px | 很小 | 冷门职位 |
| 0.2-0.5% | 15-22px | 小 | 小众职位 |
| 0.5-1% | 22-30px | 中等 | 常规职位 |
| 1-2% | 30-40px | 较大 | 热门职位 |
| 2%+ | 40-50px | 很大 | 超热职位 |

## 四、新兴职位标识设计

### 4.1 标定规则（三条件AND逻辑）

```
条件1：稀缺度指数 > 75 百分位
  └─ 通常在 70-80 分以上，反映高度人才缺口

条件2：薪资 > 中位数 (假设为20万元)
  └─ 反映职位的经济吸引力与对标要求

条件3：岗位总数 > 100
  └─ 确保市场规模足够，非极小众职位

IF (条件1 AND 条件2 AND 条件3) THEN
  标记为 "新兴职位"
  
统计：通常会识别 30-50 个新兴职位
```

### 4.2 新兴职位的视觉标记

#### 主要标记：红色星标（★）
```
位置：气泡正上方偏左
大小：14-16px
颜色：#ff4d4f (鲜红色)
透明度：100%
字体：Sans-serif 加粗
```

#### 次要标记：气泡增强
```
边框颜色：#ff4d4f (鲜红)
边框宽度：2px
边框虚实：实线
阴影效果：红色发光阴影 (blur 8px, opacity 30%)
```

#### 悬浮效果
```
当鼠标悬浮在新兴职位上：
  - 气泡放大 1.3 倍
  - 阴影增强 (blur 12px, opacity 50%)
  - 显示详细信息卡片
  - 其他气泡淡化 (opacity 30%)
```

### 4.3 非新兴职位的标记

#### 常规职位
```
气泡颜色：按行业着色，透明度 70%
边框：1px 浅灰色边框
阴影：无
```

#### 高端专业职位（薪资>90百分位但稀缺度低）
```
气泡颜色：行业色，但增加金色光晕
标记：金色小圆圈 (○)
意义：小众高薪职位，非新兴但值得关注
```

### 5.1 象限定义

```
                     高稀缺度 (>75分位)
                           ↑
                           │
        Ⅲ 高端冷门          │          Ⅰ 高端热门（新兴核心）
        (小众) ★★          │          ★★★★★
        薪资高×稀缺高      │          薪资高×稀缺高
                           │          岗位适量×需求旺
                  ─────────┼─────────→ 高薪资 (>中位数)
                           │
        Ⅳ 普遍热门          │          Ⅱ 普遍冷门
        (大众市场) ◆◆◆    │          衰退职位
        薪资中×稀缺低      │          薪资低×稀缺低
                           │
```

## 九、数据处理流程

### 9.1 数据获取与清洗

```sql
-- 获取基础数据
SELECT 
    job_title,
    median_salary,
    records_count,
    records_count_norm,
    avg_education_rank,
    avg_experience_rank,
    company_type
FROM job_summary
WHERE records_count > 50  -- 过滤极小样本
  AND median_salary > 0   -- 过滤无效薪资
  AND median_salary < 100 -- 过滤异常高薪
ORDER BY records_count DESC
LIMIT 200;
```

### 9.2 中间计算

```python
# 计算稀缺度指数
df['skill_threshold'] = ((df['avg_education_rank']/10 + 
                          df['avg_experience_rank']/10) / 2)
df['supply_shortage'] = 1 - df['records_count_norm']
df['scarcity_index'] = (df['skill_threshold'] * 0.7 + 
                        df['supply_shortage'] * 0.3) * 100

# 标定新兴职位
scarcity_75p = df['scarcity_index'].quantile(0.75)
salary_median = df['median_salary'].median()
df['is_emerging'] = (
    (df['scarcity_index'] > scarcity_75p) &
    (df['median_salary'] > salary_median) &
    (df['records_count'] > 100)
)

# 行业分类
top_industries = df['company_type'].value_counts().head(8).index
df['industry_display'] = df['company_type'].apply(
    lambda x: x if x in top_industries else '其他'
)
```

## 十、设计特色与创新

### ✨ 创新点

1. **稀缺度指数创新**
   - 结合技能门槛与岗位供给
   - 量化了职位的"人才缺口"
   - 比单纯看薪资更有洞察力

2. **四维编码充分利用**
   - 用尽了散点图的四个基本维度
   - 充分展示职位的多个关键特征
   - 信息密度高但不过载

3. **象限分析直观**
   - 清晰的分类逻辑
   - 便于快速定位新兴职位
   - 支持多角度的理解

4. **交互设计深度**
   - 支持悬浮详情卡片
   - 支持点击进入职位画像
   - 支持多维度筛选探索

### 🎯 效果目标

- **目标1**：5秒内快速识别新兴职位 → 用★标记 + 象限着色
- **目标2**：了解职位特征差异 → 用气泡大小/颜色表示
- **目标3**：支持深度探索 → 提供悬浮/点击交互
- **目标4**：支持数据导出 → 提供下载功能

## 十三、性能优化建议

### 数据优化
- 缓存计算结果，避免重复计算稀缺度指数
- 只加载Top 200职位，其他数据分页加载
- 使用数据库索引加速筛选查询

### 渲染优化
- 使用WebGL加速渲染（若点数>500）
- 启用canvas渲染而非SVG
- 使用requestAnimationFrame优化动画

### 交互优化
- 防抖(debounce)处理筛选器变化
- 节流(throttle)处理缩放、拖拽事件
- 异步加载详情卡片内容
