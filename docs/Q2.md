# 职位画像分析 · 方案A 画像总览驾驶舱设计说明

## 1. 总体设计理念

* **目标**：在单一界面内提供职位多维画像对比，包括 **技能、城市、薪资、行业** 四维信息，辅助招聘决策和人才匹配。
* **风格**：

  * 学术/竞赛风格，轻蓝灰色调，白色卡片背景，圆角面板
  * 信息密度高，但避免视觉拥挤
  * 可交互、可钻取、可对比
* **布局**：16:9 桌面仪表盘

  * 顶部：标题 + 选择器
  * 左上：职位六维综合对比
  * 右上：城市偏好分布（饼图气泡）
  * 右中：技能交叉关系图谱（整合 Top 技能）
  * 底部：薪资-学历-经验联合画像 + 热门行业分布 + 城市偏好摘要

## 2. 顶部统一选择器

* **内容**：

  * 3 个职位下拉选择框（支持最多 3 个对比职位）
  * 颜色点标识：蓝/红/绿
  * 按钮：

    * “同步分析” → 同步更新所有视图
    * “重置” → 清空选择
  * 可添加更多对比职位按钮
* **数据需求**：

  * 职位唯一 ID
  * 职位名称（显示在 Tooltip 或下拉列表中）
* **交互**：

  * 选择职位即更新所有视图
  * 鼠标悬停显示职位名称与摘要信息
  * 支持动态添加对比职位

## 3. 职位六维综合对比（左上雷达图）

* **展示内容**：

  * 六维指标：薪资待遇、技能要求、行业集中度、职业热度、城市偏好、成长空间
  * 不同职位用不同颜色的多边形表示
  * 删除冗余右侧数值表格，具体数值悬停显示 Tooltip
* **数据需求**：

  * 各职位六个维度标准化评分（0-100）
* **交互设计**：

  * Hover 显示每个维度数值
  * 点击维度可在技能交叉关系图谱中高亮相关技能
* **说明**：

  * 让用户快速识别不同职位在各维度上的强弱

## 4. 城市偏好分布（右上地图）

* **展示内容**：

  * 中国地图上各城市的饼图气泡
  * 饼图扇形：各职位在该城市的需求占比
  * 气泡大小：总需求量
* **数据需求**：

  * 城市名称与经纬度
  * 各职位在每城市的岗位数量
* **交互设计**：

  * Hover 显示城市总需求及职位分布
  * 点击城市 → 底部薪资/经验/学历联合画像及技能面板同步下钻
* **优化说明**：

  * 避免气泡重叠
  * 多职位同时比较更直观

## 5. 技能交叉关系图谱（右中）

* **展示内容**：

  * 整合 Top 技能
  * 中间大节点：共同技能（如 SQL、沟通协作）
  * 两侧小节点：职位独有技能（如数据挖掘、Spring Boot）
  * 节点大小：需求强度或共现度
  * 连线颜色：职位关联
* **数据需求**：

  * 各职位 Top 技能列表
  * 技能在职位间共现情况
  * 需求量
* **交互设计**：

  * Hover 显示技能名及岗位数
  * 点击技能 → 高亮相关职位及城市
  * 图例标明节点颜色对应职位

## 6. 薪资-学历-经验联合画像（底部左）

* **展示内容**：

  * 平行坐标图：纵轴为学历门槛、经验要求、薪资区间、中位薪资
  * 颜色线条：各职位（蓝/红/绿）
  * Insight Callout：显示洞察解读
* **数据需求**：

  * 职位对应的学历要求、经验要求、薪资区间、中位薪资
* **交互设计**：

  * Hover 线条或轴点显示具体数值
  * 点击轴 → 高亮技能交叉关系图谱中对应技能节点

## 7. 热门行业分布 & 城市偏好摘要（底部右）

* **展示内容**：

  * 热门行业分布：Top5 行业水平条形图
  * 城市偏好摘要：Top5 城市，堆叠条表示各职位占比
* **数据需求**：

  * 各职位在行业的占比
  * 各职位在城市的占比
* **交互设计**：

  * Hover 显示占比百分比
  * 点击条形 → 底部平行坐标图高亮对应职位

## 8. 多视图联动设计

| 交互触发          | 联动效果                         |
| ------------- | ---------------------------- |
| 选择/切换职位       | 更新雷达图、地图、技能图谱、底部联合画像、行业/城市摘要 |
| Hover 雷达图维度   | 高亮技能图谱相关技能                   |
| 点击地图城市        | 底部联合画像显示该城市下职位组合数据           |
| 点击技能节点        | 高亮雷达图维度及底部平行坐标线条             |
| Hover 底部平行坐标线 | 高亮技能图谱节点及城市地图中相关城市           |
| 点击行业/城市条形     | 高亮对应职位线条及技能节点                |

* **设计目标**：

  * 打通全局 → 局部 → 特征的探索路径
  * 支持用户快速发现岗位差异、技能共性、城市偏好及薪资特征
  * 提升洞察效率、减少用户视觉扫视负担

## 9. 数据预处理要求

1. **职位维度标准化**

   * 六维指标 0-100 标准化
   * 薪资区间统一单位（元/月）
2. **技能聚合**

   * 统计各职位 Top 技能
   * 计算技能共现矩阵
   * 计算技能需求量
3. **城市/行业聚合**

   * 各职位在城市/行业的岗位数量及占比
4. **学历/经验/薪资整合**

   * 构建平行坐标数据
   * 生成洞察解读文本

## 10. 总结

* **方案A 优化重点**：

  1. 技能对比采用关系图谱，解决多条条形图交叉感知难题
  2. 底部面板整合为联合平行坐标图，展示薪资、学历、经验三维关系
  3. 地理面板改为饼图气泡，清晰展示多职位城市分布
  4. 雷达图去掉冗余表格，增强视觉聚焦
* **整体效果**：

  * 信息密度高
  * 多维对比直观
  * 全局 → 局部 → 特征联动流畅
  * 适合 ChinaVis 竞赛提交
