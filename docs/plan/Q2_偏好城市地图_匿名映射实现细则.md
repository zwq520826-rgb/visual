# Q2 偏好城市地图（匿名编码）实现细则

## 1. 目标

在“城市为脱敏编码、无真实城市名”的前提下，仍能在中国地图上稳定展示“城市偏好分布”。

实现目标：
- 中国地图上各城市饼图气泡
- 饼图扇形表示各职位在该城市需求占比
- 气泡大小表示该城市总需求量
- 支持 hover 和点击下钻联动

---

## 2. 展示内容

1. 中国底图（GeoJSON）
2. 城市饼图气泡（每个匿名城市编码一个气泡）
3. 职位图例（A/B/C 固定颜色）
4. 大小图例（高/中/低总需求量）
5. 说明文案：
- `城市位置为匿名映射，仅用于相对分布对比，不代表真实地理位置`

---

## 3. 数据需求

## 3.1 输入数据（业务）

- 城市编码（如 `A050`、`C01`）
- 各职位在每城市岗位数量

推荐来源：
- `job_city_distribution`
  - 字段：`job_title`, `city`, `job_count`（其余字段可用于 tooltip 扩展）

## 3.2 输入数据（地图）

- 中国地图 GeoJSON
- 匿名映射坐标文件（新增）
  - `city_code -> [lng, lat]`

---

## 4. 匿名稳定映射方案（核心）

## 4.1 原则

- 不使用真实城市名/真实经纬度
- 同一城市编码在每次渲染中位置稳定
- 点位分布覆盖全国，不集中在单一区域

## 4.2 映射流程

1. 生成中国范围内“候选点位池”（建议 400~800 个点）
2. 对城市编码做稳定哈希（如 `md5(city_code)`）
3. 通过哈希映射到候选点位：`index = hash % N`
4. 冲突处理：若该点已被占用，采用环形探测选下一个空点
5. 对最终点位施加“确定性微抖动”（由 hash 派生），减轻视觉重叠
6. 产出并持久化映射文件：`city_pseudo_coords.json`

## 4.3 持久化建议

文件：`dataset/dataset/第二题/city_pseudo_coords.json`

示例结构：

```json
{
  "A050": [113.42, 34.71],
  "B170": [121.02, 31.56],
  "C012": [104.88, 30.92]
}
```

说明：
- 一旦生成，后续直接复用，避免每次启动重新分配导致位置变化。

---

## 5. 城市饼图气泡编码规则

## 5.1 数据聚合

对当前对比职位（最多 3 个）按城市聚合：

- `countA`：职位A在该城市岗位数
- `countB`：职位B在该城市岗位数
- `countC`：职位C在该城市岗位数
- `total = countA + countB + countC`

## 5.2 饼图扇形

- 扇形比例：`countX / total`
- 颜色固定：
  - 职位A：蓝
  - 职位B：红
  - 职位C：绿

## 5.3 气泡大小

- 半径与 `total` 映射：
  - 使用 sqrt/log 缩放避免头部城市过大
- 建议：
  - `radius = clamp(10 + k * sqrt(total), 10, 42)`

---

## 6. 交互设计

## 6.1 Hover

显示 tooltip：
- 匿名城市编码（如 `C01`）
- 城市总需求量（`total`）
- 三职位岗位数量与占比
- 可选附加：该城市经验/学历/薪资均值（若已聚合）

## 6.2 Click（联动下钻）

点击城市后触发联动事件，驱动底部面板同步：
- 薪资/经验/学历联合画像更新为“当前城市过滤态”
- 技能面板更新为“当前城市过滤态”
- 地图上高亮当前城市，其他城市降透明

建议交互状态：
- 单击：锁定城市
- 再次单击同城或点击“重置”：解除锁定

---

## 7. 避免气泡重叠（重点）

采用“三级防重叠”策略：

1. 预防：候选点位池均匀化
- 候选点位生成时设置最小间距（如 1.2°）

2. 映射期：冲突探测
- 哈希命中已占用点时环形探测空位

3. 渲染期：屏幕坐标碰撞修正
- 根据当前缩放级别将经纬度投影到像素坐标
- 若像素距离 < `(r1 + r2 + padding)`，对后者执行小幅径向偏移
- 迭代 2~3 轮直到重叠显著减少

补充建议：
- 大量城市时只显示 TopN（如前 30）+ 其余聚合“其他”
- 或在缩放阈值下逐级显示（高层聚合、低层展开）

---

## 8. 多职位对比可读性优化

1. 颜色固定且全页统一（A蓝/B红/C绿）
2. 保持职位顺序一致（选择器、图例、扇区顺序一致）
3. 提供“仅看某职位”开关（图层过滤）
4. Tooltip 同时展示数量与百分比（避免只看比例误判）
5. 提供总量排序切换（总需求/职位A需求/职位B需求/职位C需求）

---

## 9. 联动事件协议（建议）

地图对外发出统一事件：

- `city:selected`
  - payload: `{ cityCode, jobCounts, total }`
- `city:cleared`
  - payload: `{}`

底部画像与技能面板监听后执行数据刷新或前端过滤。

---

## 10. 验收标准

1. 无真实城市名情况下可稳定渲染中国地图气泡分布。
2. 同一城市编码跨刷新位置一致。
3. 气泡扇区正确反映三职位占比，半径正确反映总需求量。
4. Hover 信息完整；点击可联动底部画像与技能面板。
5. 在常见分辨率下重叠可控，不影响主要阅读。
