# ChinaVis 2024「职数洞见」Q3 薪酬待遇模式可视化设计方案

## 任务背景

Q3 任务要求：

> 不同的职位具有不同的薪酬待遇模式。请对薪酬待遇与职位、行业、地域等之间的潜在关系进行建模，识别薪酬模式和潜在的薪酬差异，利用图表的形式呈现结果并简要分析。

本任务的核心不是单纯展示“哪个职位工资高”，而是要回答：

- 不同职位的薪资模式是否不同？
- 薪资差异主要来自职位、行业、地域，还是经验学历门槛？
- 哪些职位属于高薪稳定型？哪些职位属于高薪分化型？
- 同一职位在不同行业、不同城市中是否存在明显薪资差异？
- 是否可以通过建模解释薪酬差异的来源？

结合当前数据库字段，Q3 可以重点使用以下数据：

| 数据表 | 可用字段 | 作用 |
|---|---|---|
| `data` | `job_title`、`city`、`company_type`、`median_annual_salary`、`min_annual_salary`、`max_annual_salary`、`experience_rank`、`education_rank`、`city_tier` | 明细级薪资、职位、行业、城市、学历、经验分析 |
| `job_summary` | `min_salary`、`q1_salary`、`median_salary`、`q3_salary`、`max_salary`、`std_salary`、`records_count`、`avg_experience_rank`、`avg_education_rank`、`company_type` | 职位聚合薪资分布与差异分析 |
| `job_city_distribution` | `job_title`、`city`、`job_count`、`avg_salary`、`avg_experience`、`avg_education` | 职位-城市薪资与需求分布 |
| `national_industry_stats` | `company_type`、`job_count`、`avg_median_salary`、`avg_experience_rank`、`avg_education_rank` | 行业层面的薪资和门槛对比 |

# 方案一：薪资模式地图 + 职位薪资箱线对比

## 1. 方案定位

该方案适合回答：

> 不同职位的薪资分布是否稳定？哪些职位高薪但波动大？哪些职位低薪但需求量大？薪资差异主要来自职位、行业还是地域？

核心思路是将职位薪资模式拆成三个维度：

- **薪资水平**：中位薪资 / 平均薪资；
- **薪资离散度**：四分位距、标准差；
- **市场规模**：招聘数量。

---

## 2. 视图设计

### 视图 1：职位薪资模式散点图

#### 视图形式

二维散点图 / 气泡图。

| 视觉通道 | 数据字段 | 含义 |
|---|---|---|
| 横轴 | `median_salary` | 职位薪资中位数 |
| 纵轴 | `std_salary` 或 `q3_salary - q1_salary` | 薪资波动程度 |
| 气泡大小 | `records_count` | 招聘规模 |
| 颜色 | `company_type` | 所属行业 |
| 描边 / 形状 | `city_tier` 或职位层级 | 地域或职位层级差异 |

#### 可识别的薪资模式

| 类型 | 特征 | 含义 |
|---|---|---|
| 高薪稳定型 | 薪资高、波动小 | 成熟高价值岗位 |
| 高薪分化型 | 薪资高、波动大 | 受城市、经验、行业影响明显 |
| 低薪稳定型 | 薪资低、波动小 | 标准化岗位 |
| 低薪分化型 | 薪资低、波动大 | 门槛不统一或城市差异明显 |

#### 交互设计

- **悬停气泡**：显示职位名称、行业、招聘数量、中位薪资、薪资标准差。
- **点击职位气泡**：联动更新下方箱线图和右侧城市/行业分布。
- **框选区域**：选择一类薪资模式，例如“高薪分化型”，系统自动列出代表职位。
- **筛选器**：
  - 行业筛选；
  - 城市等级筛选；
  - 招聘量阈值筛选；
  - 经验要求范围筛选。

---

### 视图 2：职位薪资箱线图对比

#### 视图形式

分组箱线图。

| 视觉通道 | 数据字段 | 含义 |
|---|---|---|
| X 轴 | `job_title` | 被选中的职位 |
| Y 轴 | `min_salary`、`q1_salary`、`median_salary`、`q3_salary`、`max_salary` | 年薪分布 |
| 箱体 | Q1、Median、Q3 | 薪资主体分布 |
| 须线 | Min、Max | 薪资上下界 |
| 颜色 | `company_type` | 行业类别 |

#### 作用

该视图用于解决散点图只能看概况、不能看具体分布的问题。

例如：

- 同样是高薪职位，A 岗位箱体很窄，说明薪资稳定；
- B 岗位箱体很宽，说明薪资差异明显；
- 某职位最大薪资远高于 Q3，可能存在少量高端岗位拉高上限。

#### 交互设计

- 点击散点图中的职位后，箱线图自动加入该职位。
- 支持最多对比 5 个职位，避免图表过密。
- 悬停箱体显示：
  - `min_salary`
  - `q1_salary`
  - `median_salary`
  - `q3_salary`
  - `max_salary`
  - `std_salary`
- 点击箱线图中的某个职位，可进一步查看该职位在不同城市或行业中的薪资变化。

---

### 视图 3：职位-城市薪资热力图

#### 视图形式

热力矩阵。

| 视觉通道 | 数据字段 | 含义 |
|---|---|---|
| 行 | `job_title` | 职位 |
| 列 | `city` 或 `city_tier` | 城市 / 城市等级 |
| 颜色深浅 | `avg_salary` 或 `median_annual_salary` | 薪资水平 |
| 单元格大小 | `job_count` | 招聘数量 |

#### 作用

用于说明：

> 同一职位在不同城市是否存在薪资差异？

例如：

- 算法工程师在一线城市薪资明显更高；
- 销售类岗位在不同城市薪资差距较小；
- 某些职位只在少数城市高薪，说明地域集中性强。

#### 交互设计

- 点击热力图单元格，显示该职位在该城市的明细统计。
- 支持切换：
  - 按城市展示；
  - 按城市等级展示；
  - 按地区聚合展示。
- 支持排序：
  - 按薪资降序；
  - 按招聘量降序；
  - 按城市差异度降序。

---

## 3. 方案优点

- 结构清晰，适合竞赛论文表达；
- 能同时覆盖职位、薪资、行业、地域；
- 图表不复杂，容易实现；
- 非常适合放入 Q3 的 3～4 张图中。

# 方案二：经验-学历-薪资图（三维柱状）联动分析

## 1. 方案定位

该方案适合回答：

> 薪资是不是随着经验和学历一起上升？哪些职位存在明显的“学历溢价”或“经验溢价”？不同岗位的薪资增长路径是否一致？

核心思想是把薪资模式理解为：

```text
职位薪资 = 经验门槛 + 学历门槛 + 行业/城市附加溢价
```

---

## 2. 视图设计

### 视图 1：经验-学历-薪资图（三维柱状对比图）

#### 视图形式

三维柱状图（X=经验，Y=学历，Z=平均薪资），用于直接展示“经验-学历组合”对应的薪资台阶。

| 视觉通道 | 数据字段 | 含义 |
|---|---|---|
| X 轴 | `experience` | 经验等级 |
| Y 轴 | `education` | 学历等级 |
| Z 轴 | `avg_salary` | 当前组合下的平均薪资 |
| 颜色 | `avg_salary`（渐变） | 薪资高低 |
| tooltip | 薪资 + 招聘量 | 当前组合统计信息 |

#### 作用

展示整体招聘市场的薪资阶梯（与现有 Q3 视图一致）：

- 经验越高是否薪资越高；
- 学历越高是否薪资越高；
- 哪些经验-学历组合薪资跃升最明显；
- 是否存在“低学历高经验高薪”或“高学历低经验高薪”的特殊模式。

#### 交互设计

- 鼠标悬停柱体，显示：
  - 平均薪资；
  - 中位薪资；
  - 招聘数量；
  - 代表职位 Top 5；
  - 代表行业 Top 5。
- 点击柱体（经验×学历组合），联动更新箱线图筛选条件。
- 支持切换统计口径：
  - 平均薪资；
  - 中位薪资；
  - 最高薪资；
  - 薪资波动程度。

---

### 视图 2：职位薪资成长曲线

#### 视图形式

多折线图。

| 视觉通道 | 数据字段 | 含义 |
|---|---|---|
| 横轴 | `experience_rank` | 经验等级 |
| 纵轴 | 平均薪资 / 中位薪资 | 薪资水平 |
| 折线 | `job_title` | 不同职位 |
| 颜色 | `company_type` | 行业类别 |

#### 作用

该视图重点展示：

> 不同职位随着经验增长，薪资增长速度是否一致。

可以识别几种模式：

| 模式 | 特征 | 示例解释 |
|---|---|---|
| 快速成长型 | 经验增加后薪资快速上升 | 技术、算法、架构类岗位 |
| 平稳成长型 | 薪资随经验缓慢提升 | 行政、运营、客服类岗位 |
| 前期高起点型 | 低经验阶段薪资已较高 | 高学历、高技术门槛岗位 |
| 后期爆发型 | 高经验阶段薪资明显跃升 | 管理类、专家类岗位 |

#### 交互设计

- 从三维柱状图中点击一个经验-学历组合后，折线图只显示该组合相关的薪资成长曲线。
- 支持多选职位对比。
- 支持切换：
  - 按职位对比；
  - 按行业对比；
  - 按城市等级对比。
- 折线末端显示职位名称，避免用户频繁查图例。

---

### 视图 3：学历 / 经验溢价贡献条形图

#### 视图形式

贡献分解条形图。

| 视觉通道 | 数据含义 |
|---|---|
| X 轴 | 职位 |
| Y 轴 | 薪资提升幅度 |
| 堆叠颜色 | 经验溢价、学历溢价、城市溢价、行业溢价 |

#### 建模方式

可以构造一个简单的解释模型：

```text
薪资差异 = 经验贡献 + 学历贡献 + 城市贡献 + 行业贡献 + 其他因素
```

实现上不一定要做复杂模型，可以先用分组均值差异近似：

```text
经验溢价 = 高经验组平均薪资 - 低经验组平均薪资
学历溢价 = 高学历组平均薪资 - 低学历组平均薪资
城市溢价 = 一线城市平均薪资 - 非一线城市平均薪资
行业溢价 = 该行业平均薪资 - 全局平均薪资
```

#### 交互设计

- 点击某个职位，展示该职位的薪资差异来源。
- 支持切换职位组：
  - 高薪职位；
  - 高需求职位；
  - 技术类职位；
  - 服务类职位。
- 鼠标悬停每个堆叠块，显示具体贡献值和占比。

---

## 3. 方案优点

- 很适合解释“薪资待遇与经验、学历之间的潜在关系”；
- 逻辑比单纯展示薪资更深入；
- 能体现建模能力；
- 图表数量控制在 3 张，符合赛题要求。

# 方案三：行业-职位-地域薪酬流动关系图

## 1. 方案定位

该方案适合回答：

> 高薪职位集中在哪些行业？这些行业主要分布在哪些城市？同一职位进入不同城市或行业后，薪资会发生什么变化？

核心思想是把薪资看成一条路径：

```text
行业 → 职位 → 城市 / 城市等级 → 薪资水平
```

---

## 2. 视图设计

### 视图 1：行业-职位-城市薪资桑基图

#### 视图形式

桑基图 / Alluvial Diagram。

| 层级 | 数据字段 | 含义 |
|---|---|---|
| 第一层 | `company_type` | 行业 |
| 第二层 | `job_title` | 职位 |
| 第三层 | `city_tier` | 城市等级 |
| 第四层 | 薪资等级 | 薪资分层 |

#### 编码方式

| 视觉通道 | 含义 |
|---|---|
| 流的宽度 | 招聘数量 |
| 流的颜色 | 薪资等级 |
| 节点高度 | 该类别招聘规模 |
| 节点颜色深浅 | 平均薪资 |

#### 薪资等级划分建议

可以根据年薪分位数划分：

| 薪资等级 | 划分方式 |
|---|---|
| 低薪 | 0%～25% |
| 中低薪 | 25%～50% |
| 中高薪 | 50%～75% |
| 高薪 | 75%～100% |

#### 交互设计

- 点击某个行业，只保留该行业流向。
- 点击某个职位，突出显示该职位在不同城市等级中的薪资流向。
- 悬停流线，显示：
  - 行业；
  - 职位；
  - 城市等级；
  - 平均薪资；
  - 招聘数量。
- 支持切换流线宽度指标：
  - 招聘数量；
  - 平均薪资；
  - 高薪岗位占比。

---

### 视图 2：行业-职位薪资矩阵

#### 视图形式

矩阵热力图。

| 视觉通道 | 数据字段 | 含义 |
|---|---|---|
| 行 | `company_type` | 行业 |
| 列 | `job_title` | 职位 |
| 颜色 | 平均薪资 / 中位薪资 | 薪资水平 |
| 单元格大小 | 招聘数量 | 市场需求 |
| 描边 | 薪资波动程度 | 稳定性 |

#### 作用

桑基图适合看路径，但不适合精确比较。  
矩阵图用于补充比较：

- 哪些行业对同一个职位给出更高薪资；
- 哪些职位在多个行业中都具有高薪资；
- 哪些行业薪酬整体偏高；
- 哪些职位只在特定行业中高薪。

#### 交互设计

- 点击矩阵单元格，联动桑基图只显示该行业-职位组合。
- 鼠标悬停显示：
  - 行业；
  - 职位；
  - 中位薪资；
  - 招聘数量；
  - 薪资波动；
  - 代表城市。
- 支持矩阵排序：
  - 按行业平均薪资；
  - 按职位平均薪资；
  - 按招聘规模；
  - 按薪资差异度。

---

### 视图 3：城市等级薪资差异坡度图

#### 视图形式

Slope Chart / 坡度图。

| 视觉通道 | 数据字段 | 含义 |
|---|---|---|
| 横轴 | `city_tier` | 城市等级 |
| 纵轴 | 平均薪资 | 薪资水平 |
| 折线 | 职位或行业 | 被比较对象 |
| 线条斜率 | 不同城市等级的薪资差异 | 城市溢价强弱 |

#### 作用

用于识别地域薪资差异：

- 某职位在一线城市和低线城市差异很大；
- 某行业在不同城市等级中薪资较稳定；
- 某些岗位存在明显“城市溢价”。

#### 交互设计

- 从桑基图点击某一职位后，坡度图只展示该职位。
- 支持同时选择多个职位对比。
- 线条颜色表示行业。
- 悬停线段显示城市等级之间的薪资差值。

---

## 3. 方案优点

- 叙事性强，适合比赛展示；
- 可以清楚讲出“行业影响职位，职位落到城市后形成不同薪资等级”；
- 视觉上比较有冲击力；
- 适合放在 Q3 中作为主图方案。

---

# 方案四：薪资差异归因分析仪表盘

## 1. 方案定位

该方案更偏“分析型”和“建模型”，适合强调：

> 薪资差异不是简单由职位决定，而是职位、行业、城市、经验、学历共同作用的结果。

核心思想是构建一个“薪资差异解释模型”，然后用可视化呈现每个因素的贡献。

---

## 2. 视图设计

### 视图 1：薪资差异归因瀑布图

#### 视图形式

瀑布图 / Waterfall Chart。

#### 表达方式

以全局平均薪资为基准：

```text
全局平均薪资
+ 职位溢价
+ 行业溢价
+ 城市溢价
+ 经验溢价
+ 学历溢价
= 目标岗位预测薪资 / 实际薪资
```

#### 示例解释

假设用户选择“算法工程师 - 互联网行业 - 一线城市”：

| 因素 | 影响 |
|---|---|
| 全局平均薪资 | 市场基础水平 |
| 职位溢价 | 算法岗位本身薪资较高 |
| 行业溢价 | 互联网行业进一步抬高薪资 |
| 城市溢价 | 一线城市薪资更高 |
| 经验溢价 | 高经验要求增加薪资 |
| 学历溢价 | 高学历要求增加薪资 |

#### 交互设计

- 用户选择：
  - 职位；
  - 行业；
  - 城市；
  - 经验等级；
  - 学历等级。
- 瀑布图实时更新薪资归因结果。
- 支持切换基准：
  - 全国平均；
  - 行业平均；
  - 城市平均；
  - 职位平均。

---

### 视图 2：职位薪资残差排行榜

#### 视图形式

横向条形图。

#### 指标设计

```text
薪资残差 = 实际薪资 - 模型预期薪资
```

#### 作用

用于识别：

| 类型 | 含义 |
|---|---|
| 正残差高 | 实际薪资高于模型预期，可能是稀缺岗位 |
| 负残差低 | 实际薪资低于模型预期，可能是供给充足或岗位标准化 |
| 残差接近 0 | 薪资符合经验、学历、城市、行业等因素预期 |

#### 交互设计

- 点击某个职位，右侧展示该职位的归因瀑布图。
- 支持选择残差类型：
  - 高估职位；
  - 低估职位；
  - 高薪但低残差；
  - 中薪但高残差。
- 悬停条形显示：
  - 实际薪资；
  - 预测薪资；
  - 残差；
  - 招聘数量；
  - 所属行业。

---

### 视图 3：薪资影响因素重要性雷达图

#### 视图形式

雷达图 / 因素画像图。

| 维度 | 含义 |
|---|---|
| 职位影响 | 职位本身对薪资的解释力 |
| 行业影响 | 行业类别对薪资的解释力 |
| 城市影响 | 地域对薪资的解释力 |
| 经验影响 | 经验要求对薪资的解释力 |
| 学历影响 | 学历要求对薪资的解释力 |
| 波动程度 | 薪资不确定性 |

#### 作用

用于形成不同职位的薪资机制画像：

| 薪资机制 | 特征 |
|---|---|
| 职位驱动型 | 职位本身决定薪资 |
| 行业驱动型 | 同一职位在不同行业差异明显 |
| 城市驱动型 | 不同城市薪资差异明显 |
| 门槛驱动型 | 经验和学历要求显著影响薪资 |
| 不稳定型 | 薪资波动大，内部差异强 |

#### 交互设计

- 选择多个职位后，雷达图叠加对比。
- 点击雷达图某一维度，如“城市影响”，下方自动列出城市差异最大的职位。
- 支持归一化显示，避免高薪职位数值过大压制其他职位。

---

### 视图 4：薪资模式聚类图

#### 视图形式

二维降维散点图 / 聚类图。

#### 可用特征

可以用以下字段构建职位薪资模式向量：

```text
[
  median_salary,
  q1_salary,
  q3_salary,
  std_salary,
  avg_experience_rank,
  avg_education_rank,
  records_count,
  total_shannon_entropy
]
```

#### 聚类结果解释

| 聚类类型 | 特征 |
|---|---|
| 高薪高门槛型 | 薪资高，经验学历要求高 |
| 高薪波动型 | 薪资高，但标准差大 |
| 大众稳定型 | 招聘量大，薪资中等，波动小 |
| 低薪低门槛型 | 薪资低，经验学历要求低 |
| 稀缺潜力型 | 招聘量不一定大，但薪资残差高 |

#### 交互设计

- 点击某个聚类，右侧展示该类代表职位。
- 框选散点，自动生成该类薪资模式描述。
- 支持切换颜色编码：
  - 聚类类别；
  - 行业；
  - 城市等级；
  - 薪资等级。
- 点击职位点，联动瀑布图和雷达图。

---

## 3. 方案优点

- 最能体现“建模”能力；
- 适合竞赛答辩时讲方法深度；
- 能从“展示薪资”升级到“解释薪资差异”；
- 但实现难度比前三个方案更高。

# 最终采用方案

Q3 最终采用：**方案二：经验-学历-薪资图（三维柱状）联动分析**。

采用理由：

- 与当前已实现接口和页面结构完全一致，改造成本可控；
- 以“经验 × 学历 → 薪资”主线叙事，符合赛题的“潜在关系建模”要求；
- 可通过箱线图和平行坐标联动补足分布与解释层，避免单图结论过浅。

# Q3 可以形成的分析叙事

最终在论文或答辩中可以这样讲：

```text
        ↓

```

# 最终建议

Q3 不建议只保留一个单图（不管是“三维柱状图”还是“薪资排行榜”），因为单图只能回答“谁高谁低”，很难完整支撑“潜在关系建模”和“模式识别”。

更推荐采用你们当前可落地的三图闭环：

- **总览图**：经验-学历-薪资图（三维柱状）；
- **分布图**：箱线图（城市/公司类型下钻）；
- **解释图**：交互式多维图（平行坐标 + 散点联动）。

这样既能满足“职位、行业、地域”的多维关系表达，也能体现可视分析系统的交互性和分析深度。
