# Q1～Q5 当前前端视图详细描述（基于现有实现）

## 1. 文档范围与说明
- 本文针对当前前端代码中的 `Q1` 到 `Q5` 五个任务页进行视图描述。
- 描述依据为 `fronted/src/components/tabs` 与对应图表组件的实际实现（非设计草图）。
- 重点覆盖：页面结构、视觉层级、核心图表语义、交互联动、状态反馈与响应式行为。

## 2. 全局框架（Q1～Q5 共享）
- 顶层是单页仪表盘结构：固定顶部导航 + Tab 切换内容区。
- 顶部导航使用玻璃拟态风格，包含 5 个任务入口：
  - `q1` 职位差异度分析
  - `q2` 职位画像分析
  - `3d-chart` 薪资多维分析（即 Q3）
  - `q4` 地域数据分析
  - `q5` 行业动态趋势
- 内容区默认是浅米色渐变卡片容器；当切到 `Q5` 时会去掉外层卡片背景，让大画布类视图（引力图/星云图）获得更大空间。
- 全局切换动画为淡入淡出，避免重位移动画干扰图表阅读。
- 移动端下 Tab 纵向堆叠，指示器隐藏，内容区内边距缩小。

## 3. Q1 任务视图：职位差异度分析

### 3.1 页面布局
- 整体为左右分栏：
  - 左侧（主视图）：职位分布散点气泡图。
  - 右侧（辅助视图）：上方雷达对比图，下方蝴蝶差异图。
- 桌面端比例约 `2:1`；在窄屏下改为纵向并列/重排。

### 3.2 视图 A：职位分布散点气泡图（左）
- 语义：以职位为点，表现经验、薪资、学历/热度等维度关系。
- 控件区：
  - 城市选择（城市模式时可见）。
  - X/Y 轴指标切换。
  - 气泡大小指标切换。
  - `Top` 标注开关。
- 图例区：
  - 按“职位层级”展示颜色图例（如平薪新人、优薪技能等）。
  - 支持点击图例做类别显隐过滤。
- 交互：
  - 点选气泡可进入“已选职位”列表。
  - 支持清空选择。
  - 已选职位会在图下方展示摘要（薪资、经验、学历均值）。

### 3.3 视图 B：职位多维对比雷达图（右上）
- 输入：来自散点图中选中的职位。
- 条件：支持 2～3 个职位对比；未选时显示引导文案。
- 维度：薪资水平、平均经验、平均学历、招聘人数、薪资标准差、行业泛化性。
- 特点：
  - 对各维度做动态归一化（0～100）以便同屏比较。
  - 图例和 Tooltip 显示对应职位真实值。

### 3.4 视图 C：职位差异度蝴蝶图（右下）
- 条件：仅支持 2 个职位；少于 2 或多于 2 都显示提示状态。
- 形式：左右镜像柱状图。
  - 左柱：职位 A。
  - 右柱：职位 B。
- 指标：招聘人数、平均薪资、平均经验、平均学历、薪资波动、行业泛化性。
- 特征：
  - 每个维度标题右侧显示“差异贡献占比”。
  - Tooltip 同时展示两侧真实值与维度贡献。

### 3.5 Q1 内部联动
- `Q1Tab` 通过轮询散点组件的已选节点（300ms）同步到右侧两个图。
- 一个主选择动作即可驱动“雷达（多目标）+ 蝴蝶（双目标）”两条分析路径。

## 4. Q2 任务视图：职位画像分析（三主视图）

### 4.1 页面结构与视觉层级
- 采用“仪表板叙事”结构：
  - 顶部 Hero 概要卡。
  - 职位选择与动作区。
  - 三个主视图面板（轮廓图、桑基图、偏好城市地图）。
  - 底部统计条。
- 主题色是冷色蓝系，强调分析工具感；卡片均为白底轻阴影。

### 4.2 顶部控制区
- Hero 区展示标题与说明，并含：
  - 分析周期下拉（2024Q1/Q2/Q3）。
  - 导出按钮（当前为界面保留动作位）。
- 职位选择区：
  - 3 个统一选择器（职位 A/B/C，最多 3 个）。
  - `同步分析` 按钮：一次触发多视图数据加载。
  - `重置` 按钮：清空所有选择与视图状态。

### 4.3 视图 A：轮廓对比图（Silhouette）
- 展示形态：卡片 + 星级矩阵。
- 维度：薪资水平、技能要求、行业集中度、职业热度、城市分布广度。
- 表达方式：
  - 每个职位有独立色（A 蓝 / B 红 / C 绿）。
  - 各维度按相对值映射为 1～5 星。
  - 薪资行保留数字标签，便于读值。

### 4.4 视图 B：路径流向图（Sankey）
- 路径语义：技能水平 → 行业分布 → 市场需求 → 薪资水平。
- 数据组织：
  - 多职位数据被合并到一张桑基图。
  - 连线按职位槽位上色并带有职位归属信息。
- 交互提示：
  - 节点 Tooltip 显示分类。
  - 连线 Tooltip 显示来源、去向与流量。

### 4.5 视图 C：偏好城市地图
- 地图底图：全国地图（移除南海诸岛插图，主图更聚焦）。
- 点标记：
  - 每个城市编码用三扇区圆饼表示 A/B/C 职位占比。
  - 外圈高亮当前选中城市。
- 控件丰富：
  - 容器宽高、地图缩放、中心点、宽高比、布局尺寸均可滑杆调参。
  - 支持按钮式放大/缩小/平移/复位。
  - 同时支持鼠标滚轮缩放与拖拽漫游。
- 侧信息：
  - 城市锁定摘要（映射城市、坐标、总需求、A/B/C 需求、排名）。
  - 城市下钻卡片（A/B/C 在该城占比、薪资/经验/学历摘要）。

### 4.6 底部统计条
- 显示样本记录数、覆盖行业数、覆盖城市数、分析维度数。
- 与上方主视图组成“图+指标”双层信息结构。

### 4.7 Q2 关键联动逻辑
- 同步分析会并发加载：轮廓数据、桑基数据、嵌套数据、城市广度数据。
- 地图点击城市后，详情面板与下钻区域同步更新。
- 职位选择一套输入驱动三主视图，保证叙事一致性。

## 5. Q3 任务视图：薪资多维分析

### 5.1 页面结构
- 上半区：
  - 左：3D 柱状对比图。
  - 右：箱线图分析。
- 下半区：
  - 一整块双视图联动（聚类降维散点 + 平行坐标）。

### 5.2 视图 A：3D 柱状对比图
- 轴语义：经验（X）× 学历（Y）× 薪资（Z）。
- 视觉编码：柱体颜色随薪资高低由浅蓝到深蓝渐变。
- 交互：
  - 点击柱体会抛出当前经验/学历组合。
  - 提供“开启/关闭手势摄像头”按钮。
  - 开启后可通过手势控制视角（含平滑插值与状态提示）。

### 5.3 视图 B：箱线图分析
- 接收来自 3D 图的经验/学历筛选条件。
- 提供二级筛选：城市、公司类型、视图类型（按城市/按公司类型）。
- 目标：在同一经验+学历分组下观察薪资分布离散程度与异常值。

### 5.4 视图 C+D：聚类降维 + 平行坐标联动
- 上方工具栏可调：
  - 聚类簇数、聚类算法、后端样本量、平行坐标抽样量。
- 左图（降维散点）：
  - 语义为薪酬模式在低维空间的分群结构。
  - 可框选/图例筛选簇。
- 右图（平行坐标）：
  - 展示多维特征关系（学历、经验、城市等级、行业等）。
  - 轴刷选可反向联动左图。
- 底部摘要条实时反馈：总职位数、抽样量、联动选中数、坐标语义、聚类算法等。

### 5.5 Q3 联动主线
- 3D 柱点击 → 更新箱线图条件。
- 聚类散点选择 ↔ 平行坐标刷选双向联动。
- 形成“宏观分群 + 局部分布”的上下层分析闭环。

## 6. Q4 任务视图：地域数据分析

### 6.1 页面整体
- 顶部控制栏 + 质量指标条 + 双层图形区。
- 风格上采用科研蓝白配色，强调“模型参数→结果视图”的分析流程。

### 6.2 顶部控制与质量反馈
- 参数项：
  - 簇数（4/5/6/7）。
  - 算法（当前暴露 `KMeans`）。
  - 度量指标（职位数量/行业占比/区位商）。
- 操作项：清除簇筛选。
- 质量条：展示地域数、聚类算法、Silhouette、DBI。

### 6.3 主视图 C：城市等级矩形热力图
- 位置：中上区域左侧。
- 语义：城市（行）× 公司类型（列），颜色表示指标强度。
- 交互：点击城市单元可联动地域详情与相似地域图。
- 辅助控件：一线/二线/三线/其他城市等级切换。

### 6.4 视图 B：精简单地域画像
- 位置：主视图右侧。
- 内容：
  - KPI（城市等级、岗位数、平均薪资、中位薪资）。
  - 行业 Top5、职位 Top5 条形图。
  - 多维特征雷达图（学历门槛、经验门槛、规模强度、成熟度、技能集中）。

### 6.5 视图 A：地域招聘画像散点图
- 位置：下层左侧。
- 编码：
  - 每个点代表一个地域。
  - 颜色表示簇。
  - 点大小表示岗位规模。
  - X/Y 轴可切换多个特征（薪资、集中度、门槛、规模等）。
- 叠加能力：
  - 可显示从热力图选中城市到相似城市的连线，表达相似度路径。

### 6.6 相似地域招聘画像图
- 位置：下层右侧。
- 形式：水平条形图展示 TopN 相似城市及相似度百分比。
- 作用：给出“当前城市”在招聘结构上的可比对象。

### 6.7 Q4 联动主线
- 热力图点选城市 / 散点图点选地域 → 更新地域画像 + 相似地域图。
- 簇筛选会限制散点显示集合，便于聚焦局部簇行为。

## 7. Q5 任务视图：行业动态趋势

### 7.1 页面机制
- Q5 采用两页式布局（分页器控制 `第1/2页`）。
- 切页自动触发对应数据加载。

### 7.2 第 1 页结构

#### 7.2.1 左右双图（并排）
- 左：Math-Based 多维 Icon 柱状图。
- 右：Math-Based 连续型进度条图。
- 两图共享同源排名数据，突出“同数据双表达”。

#### 7.2.2 引力网络主区（整行）
- 顶部是 5 张“新兴岗位卡片”（可点选岗位）。
- 控制区支持：
  - 城市等级过滤。
  - 行业节点上限滑杆。
- KPI 条展示核心岗位、需求量、覆盖度、破壁熵、枢纽分等。
- 主图 `Q5ForceAtlasGraph` 特征：
  - 将 5 个岗位网络合并到长卷画布，围绕当前激活岗位居中。
  - 网络含“核心行业”与“星尘行业”层次。
  - 连线颜色映射薪资高低，节点大小可随评分缩放。

### 7.3 第 2 页结构

#### 7.3.1 上半：双环玫瑰极坐标图 + Top2 卡片侧栏
- 内外双环展示行业规模与门槛/经验相关信息。
- 带放大缩小按钮，可微调环半径。
- 支持扇区点击、悬停事件向下游视图传递。

#### 7.3.2 下半：行业星云图 + 信息面板
- 星云图是多 Canvas 叠层渲染（地形/热力/迷雾/实体层）。
- 支持 WASD/方向键移动、双击跳转、悬停与选择。
- 右侧信息面板提供：
  - Fog、热力强度、足迹衰减、地形模式、平滑强度等控制。
  - 颜色图例（薪资低→高）。
  - 行业详情或职位详情（含 Top 职位列表、按钮动作位）。

### 7.4 Q5 关键联动
- 第 1 页：岗位卡切换会更新激活网络与 KPI。
- 第 2 页：
  - 玫瑰扇区点击会触发星云聚焦与过渡动画。
  - 星云悬停/选中会反向驱动侧栏内容。
  - 职位选择可回写行业选中态。

## 8. 现状总结（面向后续美化/重构）
- 现有 Q1～Q5 已形成“单页多任务、强图表密度、跨视图联动”的完整分析平台骨架。
- Q2/Q4/Q5 的交互复杂度较高，已具备较完整的数据控制台形态。
- Q3 在“3D交互 + 统计分布 + 聚类联动”上层次最深，适合后续重点优化可读性与操作引导。
- 后续若进行统一美化，建议优先统一三部分：
  - 控件视觉语言（按钮/下拉/滑杆）。
  - 图例与状态提示样式（加载/空态/错误态）。
  - 任务页标题层级与信息密度节奏（避免视觉拥挤）。
