# Q2 三主视图实现计划（轮廓对比图 + 路径流向图 + 偏好城市地图）

本文是 Q2 新版可视化页面（参考 `docs/Q2.png` / Image4）的实施蓝图，覆盖数据口径、接口编排、组件拆分、交互联动与迭代顺序。

## 1. 目标与范围

## 1.1 页面目标

- 支持最多 3 个职位并行对比；
- 在一个页面中完成：
  1) 轮廓对比图（六维）
  2) 路径流向图（Sankey）
  3) 偏好城市地图（中国底图 + 匿名饼图气泡）
- 提供“同步分析 / 重置 / 分析周期（静态） / 导出报告（占位）”等操作入口。

## 1.2 本期边界

- 本期不新增数据库表；
- 本期优先复用现有接口：`/positions/parallel`、`/positions/sankey`、`/positions/nested_bar`、`/positions/job_titles`；
- 本期地图采用“匿名映射”，不暴露真实城市名。

---

## 2. 数据与口径设计

## 2.1 输入参数

- `job_titles[]`：最多 3 个职位；
- `sankey_mode`：默认 `compare`；
- `sankey_dimensions`：默认 `skill_level,industry_spread,market_demand`。

## 2.2 六维指标口径（轮廓对比图）

前 4 维直接来自现有 `/positions/parallel` 的归一化输出，后 2 维用代理指标补齐。

1. `薪资水平`：`parallel.values[0]`
2. `技能要求`：`parallel.values[1]`
3. `行业集中度`：`parallel.values[2]`
4. `热度`：`parallel.values[3]`
5. `成长空间`（代理）：基于 `nested_bar.micro.salary_statistics` 的 `q3 - q1`，对三职位 min-max 归一化到 0-100
6. `稳定性`（代理）：基于 `std_salary` 或 `q3-q1` 反向值归一化（波动越小分越高）

说明：第 5、6 维是本期“可实现代理值”，后续可替换为更严格业务定义。

## 2.3 路径流向图口径

- 来源：`/positions/sankey?mode=compare&job_titles=...`
- 流向层级固定：
  - 技能水平 -> 行业分布 -> 市场需求 -> 薪资水平
- 展示维度：节点占比（默认） + 连线占比

## 2.4 城市偏好地图口径（匿名）

- 来源：`nested_bar` 的 `micro_analysis.all_cities`（对每个职位）
- 聚合逻辑：
  - 取三职位城市并集；
  - 以 `job_count` 作为城市总量；
  - 每个城市的饼图扇区表示三个职位占比。

---

## 3. 匿名城市地图方案（中国底图）

## 3.1 原则

- 城市真实名称不可展示；
- 地图保留中国轮廓，用于“相对分布理解”；
- 所有标签显示匿名编码（如 `C01`, `H08`, `D04`）。

## 3.2 映射机制（推荐）

- 维护固定映射函数：`hash_city_code -> anchor_point`；
- `anchor_point` 来自预置点位池（覆盖华北、华东、华南、西南、东北等区域）；
- 同一编码每次进入页面映射到同一点位（稳定可复现）。

## 3.3 前端声明

- 在地图右上角显示：`城市以匿名编码显示`；
- 在图注显示：`位置为匿名映射，仅用于相对分布对比`。

## 4. 接口编排与数据流

## 4.1 接口清单

1. `GET /api/positions/job_titles`
2. `GET /api/positions/parallel?job_titles=...`
3. `GET /api/positions/sankey?mode=compare&job_titles=...&dimensions=skill_level&dimensions=industry_spread&dimensions=market_demand`
4. `GET /api/positions/nested_bar?job_titles=...&detail_job=...`

## 4.2 调用顺序

- 页面初始化：
  - 拉取 `job_titles`；
  - 默认填充前 3 个职位；
  - 触发一次 `同步分析`。
- 同步分析：
  - 并发请求 `parallel` + `sankey` + `nested_bar(宏观)`；
  - 轮询每个职位再拉 `nested_bar(detail_job=职位X)`，拼接城市分布用于地图。

## 4.3 前端聚合模型（建议）

```ts
type Q2ViewModel = {
  jobs: string[]
  silhouette: {
    dimensions: string[]
    series: Array<{ jobTitle: string; scores: number[] }>

  sankey: {

  }
  cityMap: {
    points: Array<{
      cityCode: string
      pseudoName: string
      coord: [number, number]
      total: number
      split: [number, number, number]
    }>
  }
  footerStats: {
    sampleCount: number

  }

```

## 6. 交互设计（详细）

## 6.1 顶部交互

- 职位选择器（最多3个）：
  - 变更后不立即请求，点击“同步分析”统一刷新；
- `同步分析`：触发全部视图刷新；
- `重置`：清空职位并清图；
- `导出报告`：本期先保留按钮与提示（后续扩展 PDF/PNG）。

## 6.2 轮廓对比图交互

- Hover 星级：显示该维度原始数值与归一化值；
- 点击某维度行：
  - 高亮 Sankey 中相关节点（例如“技能要求”行高亮 skill_level）；
  - 地图保留当前状态（不重算）。

## 6.3 路径流向图交互

- Hover 节点：显示占比、样本数、关联上下游；
- 点击节点：
  - 左侧轮廓图高亮对应职位列；
  - 右侧地图仅高亮相关职位颜色层。

## 6.4 地图交互

- Hover 气泡：显示匿名城市编码、总量、职位占比；
- 点击气泡：
  - 锁定该城市；
  - 左图与中图进入“城市过滤态”（仅高亮，不重新请求）。

## 6.5 状态与异常

- 加载中：每图独立 skeleton；
- 空态：`未找到数据，请调整职位组合`；
- 错误态：显示接口错误并保留上次成功结果。

- 画布：16:9 适配，桌面优先；
- 主体三栏：`3 : 4 : 3`；
- 色板：职位 A/B/C 固定 `蓝/红/绿`；
- 字体层级：
  - 页面标题 40-48
  - 面板标题 28-34
  - 正文与标签 14-18
- 卡片风格：浅蓝灰背景、白色圆角面板、低阴影。

## 9. 验收标准

1. 3 个职位可正常同步刷新三主视图；
2. 轮廓图 6 维评分完整显示；
3. Sankey 路径完整（四层）；
4. 地图显示中国底图 + 匿名编码饼图气泡；
5. 交互联动（高亮/锁定）可用；
6. 页面在 1440px 与 1920px 下无明显布局破坏。
