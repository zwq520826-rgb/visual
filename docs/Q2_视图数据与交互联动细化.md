# Q2 三主视图：数据、交互与联动细化方案

## 1. 目标

将三主视图方案落地为可实现的产品规格，明确：

- 每个视图用什么数据
- 如何编码展示
- 如何交互
- 视图间如何联动

---

## 2. 数据来源与接口

## 2.1 顶部选择器

- 接口：`GET /api/positions/job_titles`
- 输出：职位列表（最多取前100）

## 2.2 轮廓对比图

- 主接口：`GET /api/positions/parallel?job_titles=...`
- 辅助接口：`GET /api/positions/nested_bar?job_titles=...&detail_job=...`

字段映射：

- 薪资水平 -> `parallel.positions[].values[0]`
- 技能要求 -> `parallel.positions[].values[1]`
- 行业集中度 -> `parallel.positions[].values[2]`
- 热度可作为城市广度代理的一部分 -> `parallel.positions[].values[3]`
- 城市分布广度 -> `micro_analysis.all_cities` 的去重/覆盖度归一化
- 成长空间 -> `salary_statistics.q3 - salary_statistics.q1` 归一化
- 稳定性 -> 以 `std_salary` 或分位差反向归一化

## 2.3 路径流向图

- 接口：
  `GET /api/positions/sankey?mode=compare&job_titles=...&dimensions=skill_level&dimensions=industry_spread&dimensions=market_demand`

字段映射：

- 节点：`nodes[]`
- 路径：`links[]`
- 分层：`categories[]`

## 2.4 偏好城市地图

- 接口：`GET /api/positions/nested_bar?job_titles=...&detail_job=...`
- 字段：`micro_analysis.all_cities[]`（`city`, `count`, `percentage`）

聚合逻辑：

- 对 A/B/C 三职位取城市并集
- 每城生成：
  - `total = countA + countB + countC`
  - `split = [countA, countB, countC]`

匿名映射：

- 城市显示名：`C01/C02/...`
- 原始编码仅在 tooltip 内出现（可选）

---

## 3. 视图编码规格

## 3.1 轮廓对比图（星级矩阵）

- 输入值范围：0-100
- 星级映射：
  - `0-20 -> 1星`
  - `20-40 -> 2星`
  - `40-60 -> 3星`
  - `60-80 -> 4星`
  - `80-100 -> 5星`
- 色彩：
  - A 蓝 `#2f6dff`
  - B 红 `#ef5350`
  - C 绿 `#37b568`

## 3.2 路径流向图（Sankey）

- `nodeWidth`: 12-18
- `nodeGap`: 16-30
- `lineStyle.opacity`: 0.3-0.45
- `lineStyle.curveness`: 0.45-0.55
- tooltip 输出：
  - 边：`source -> target + value + 占比`（若可计算）
  - 点：`节点名称 + 类别 + 样本量`

## 3.3 偏好城市地图（中国底图+饼图气泡）

- 底图：`china.json`（本地资源）
- 气泡大小：`symbolSize = clamp(total * k, min, max)`
- 饼图半径：与 `total` 同步分级
- 图例：
  - 颜色图例（A/B/C）
  - 综合偏好比大小示意

## 4. 交互设计

## 4.1 顶部控制

- 选择职位后点击“同步分析”触发全视图刷新
- “重置”清空状态并回到初始展示
- “导出报告”保留入口，后续接 PDF/PNG

## 4.2 轮廓对比图交互

- Hover 星级单元：显示原始分值
- 点击维度：向其他视图发送高亮信号（例如高亮对应路径层）

## 4.3 路径流向图交互

- Hover 路径：高亮相邻节点
- 点击节点：
  - 左侧只强调关联维度行
  - 右侧地图仅突出相关职位颜色层

## 4.4 地图交互

- Hover 城市：显示编码、总量、A/B/C 占比
- 点击城市：锁定该城市（再次点击取消锁定）
- 锁定时：
  - 左侧可提示“城市过滤态”
  - 中间路径图保持但加“已锁定城市”提示

---

## 5. 联动规则

1. 顶部同步分析 -> 三视图同时刷新
2. 左图点击维度 -> 中图对应层高亮
3. 中图点击节点 -> 左图相关维度强调 + 右图相关职位强调
4. 右图点击城市 -> 左/中进入“锁定提示态”
5. 重置 -> 清除所有高亮、锁定、筛选

---

## 6. 异常与空态策略

- 任一接口失败：
  - 保留上次成功数据
  - 面板局部展示错误文案
- 无数据：
  - 显示 `暂无数据，请调整职位组合`
- 匿名映射不足：
  - 超出点位池时循环映射并微偏移，避免重叠

---

## 7. 性能与工程建议

- 三主接口并发请求，减少首屏等待
- 地图饼图层按 TopN 城市裁剪（默认 10）
- 组件化拆分：
  - `Q2Silhouette`
  - `Q2Sankey`
  - `Q2CityMap`
  - `Q2StatsFooter`
- 将匿名映射函数独立为 util，确保可复现
