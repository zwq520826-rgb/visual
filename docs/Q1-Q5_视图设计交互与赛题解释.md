# Q1～Q5 视图设计、交互机制与赛题解释说明

## 1. 文档目的
本文面向当前系统实现，说明 Q1～Q5 五个任务页的：
- 视图设计意图（为什么这样排版、这样编码）
- 交互机制（用户如何操作、视图如何联动）
- 赛题解释路径（这些图如何回答题目要求）

说明依据：`fronted/src/components/tabs` 及相关图表组件、`services` 与 `routes` 当前实现。

## 2. 全局设计原则
- 多任务统一工作台：通过顶部 Tab 在 Q1～Q5 间切换，保持同一数据语境。
- 主辅视图结构：每个任务都采用“主图 + 辅图 + 指标摘要/筛选控制”的分析布局。
- 以联动替代堆图：核心交互是“点击一个视图，驱动其他视图更新”，而不是静态拼贴。
- 统一状态反馈：加载中、空数据、错误提示均有明确反馈，保证演示可控。

## 3. Q1 职位差异度分析

### 3.1 任务目标对应
赛题要求是“从行业类别、薪资、经验等多维属性量化职位差异度”。

### 3.2 视图设计
- 视图 A（主）：职位散点气泡图
  - 点 = 职位，位置编码经验/薪资等，气泡大小可切换（默认招聘规模）
  - 颜色按职位层级（平薪新人、基薪普及、优薪技能、高新管理）
- 视图 B：多职位雷达对比
  - 将 2～3 个职位投影到统一雷达维度，做结构对比
- 视图 C：双职位蝴蝶图
  - 仅对 2 个职位，按维度左右镜像展示真实值，附差异贡献占比

### 3.3 交互机制
- 主图点选职位，右侧雷达/蝴蝶自动联动。
- 主图支持 X/Y 轴指标切换、气泡指标切换、Top 标注、图例类别显隐。
- 已选职位列表支持清空，便于快速重试比较组合。

### 3.4 如何解释赛题
- 散点图负责“发现差异候选”。
- 雷达图负责“多维轮廓解释”。
- 蝴蝶图负责“差异拆解与贡献归因”。
三者组成“发现 -> 比较 -> 解释”的完整差异度分析链路。

## 4. Q2 职位画像分析

### 4.1 任务目标对应
赛题要求是“展示职位画像（关键技能、偏好城市、薪酬待遇等）”。

### 4.2 视图设计
- 视图 A：轮廓对比图（Silhouette）
  - 维度含薪资、技能、行业集中度、职业热度、城市分布广度
  - 强调“同一职位在多维上的画像轮廓”
- 视图 B：路径流向图（Sankey）
  - 路径为“技能水平 -> 行业分布 -> 市场需求 -> 薪资水平”
  - 强调职位画像背后的结构性迁移关系
- 视图 C：偏好城市地图
  - 城市匿名编码，城市点位显示职位 A/B/C 分布占比
  - 强调“职位画像的地域偏好差异”

### 4.3 交互机制
- 顶部最多选择 3 个职位，点击“同步分析”并发刷新三主图。
- 城市地图支持缩放、平移、尺寸微调、槽位显隐（A/B/C）。
- 点击城市可查看城市下钻摘要（总需求、A/B/C 贡献、薪资/经验/学历）。

### 4.4 如何解释赛题
- 轮廓图给出职位画像的“静态剖面”。
- 桑基图给出画像形成的“结构路径”。
- 地图给出画像落地的“地域分布”。
从“属性 -> 结构 -> 空间”三个角度覆盖职位画像要求。

## 5. Q3 薪酬模式建模与差异识别

### 5.1 任务目标对应
赛题要求是“建模识别薪酬模式与潜在差异，并图表化呈现”。

### 5.2 视图设计
- 视图 A：3D 薪资柱图（经验 × 学历 × 薪资）
  - 直接呈现经验/学历组合下的薪资面
  - WebGL 不可用时自动降级到 2D 热力
- 视图 B：箱线图
  - 对点击到的经验/学历切片做薪资分布分析
  - 观察中位数、离散度、极值
- 视图 C+D：聚类散点 + 平行坐标
  - 聚类散点展示薪酬模式分群
  - 平行坐标展示各群在多维特征上的结构差异

### 5.3 交互机制
- 3D 柱点击联动箱线图筛选条件。
- 聚类视图工具栏可调簇数、算法、样本量、坐标模式、轮廓模式。
- 散点与平行坐标双向联动（选中/刷选互相反馈）。

### 5.4 如何解释赛题
- 3D+箱线图回答“薪酬与经验/学历的局部关系与分布差异”。
- 聚类+平行坐标回答“全局薪酬模式建模与群间差异解释”。
兼顾“统计分布视角”和“模式识别视角”。

## 6. Q4 地域招聘画像与相似地域识别

### 6.1 任务目标对应
赛题要求是“总结地域招聘画像，展示地域特征，并识别相似地域”。

### 6.2 视图设计
- 视图 C（主）：城市等级矩形热力图
  - 维度为城市 × 公司类型
  - 颜色深浅按度量指标（职位数量/行业占比/区位商）
- 视图 A：地域招聘散点图（当前版本）
  - 横纵坐标可切换（默认 PCA1/PCA2）
  - 点大小 = 招聘数量（`job_count`）
  - 点颜色深浅 = 行业数量（`industry_count`，冷暖连续色阶）
  - 提供“密集区展开”与“相似连线显示”开关，默认显示相似连线
  - 内置防重叠布局，避免密集点互相遮挡
- 视图 B：单地域画像
  - KPI + 行业 Top5 + 职位 Top5 + 雷达
  - 雷达维度聚焦门槛、结构、高薪占比、头部行业/职位占比
- 相似地域视图
  - 以条形图显示 TopN 相似城市及相似度

### 6.3 交互机制
- 热力图点击城市后，联动更新：散点高亮语境、单地域画像、相似地域条形图。
- 顶部控制栏可切换簇数/算法/度量指标，质量条实时显示 Silhouette 与 DBI。
- 散点图支持坐标切换，支持相似连线开关，tooltip 同时给出簇信息与城市属性。

### 6.4 如何解释赛题
- 热力图回答“地域结构差异在哪里”。
- 散点图回答“地域在特征空间如何分布，哪些点具有共同性质”。
- 单地域画像回答“某一地域具体画像是什么”。
- 相似地域图回答“哪些地域可归为相似策略组”。
形成“全局分布 -> 点位结构 -> 个体画像 -> 相似推荐”的地域分析闭环。

## 7. Q5 行业发展动态与新兴职位识别

### 7.1 任务目标对应
赛题要求是“总结行业发展动态，并发现急需人才的新兴职位并说明理由”。

### 7.2 视图设计
Q5 采用双页结构：
- 第 1 页
  - 多维 Icon 柱状图
  - 连续型进度条图
  - 行业引力网络图（核心/星尘行业、破壁路径）
- 第 2 页
  - 双环玫瑰极坐标图（行业结构）
  - 行业星云图（高维关系的沉浸式浏览）
  - 右侧细节面板（行业/职位详情与控制）

### 7.3 交互机制
- 第 1 页：可点选前 5 新兴岗位卡片，联动引力网络与 KPI。
- 第 1 页控制：城市等级筛选、行业节点上限。
- 第 2 页：玫瑰图扇区点击可驱动星云聚焦；星云悬停/选择可反向更新侧栏。
- 第 2 页控制：迷雾、热力强度、衰减、地形模式、平滑等可视参数调节。

### 7.4 如何解释赛题
- 排行类图回答“哪些岗位正在升温”。
- 引力网络回答“岗位与行业之间的扩散与破壁路径”。
- 玫瑰+星云回答“行业结构与职位活跃度如何动态演化”。
最终可给出“新兴职位识别 + 行业枢纽解释 + 人才紧缺理由”。

## 8. 五题合并的分析叙事
- Q1 先定量识别“职位差异”。
- Q2 再刻画“职位画像”。
- Q3 建模“薪酬模式”。
- Q4 转向“地域画像与相似地域”。
- Q5 收敛到“行业动态与新兴岗位决策”。

这五题在当前系统中形成从“职位个体”到“地域群体”再到“行业网络”的多尺度分析路径，可直接支撑招聘策略与求职决策解释。
