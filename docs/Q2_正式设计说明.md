# Q2 职位画像分析三主视图正式设计说明

## 1. 设计目标

Q2 页面定位为“总览型分析界面”，作为职位画像分析的主入口。页面围绕三个核心问题展开：

1. 这个职位长什么样（画像轮廓）
2. 这个职位为何形成当前薪资结果（机制路径）
3. 这个职位偏好哪些城市（空间分布）

因此，本设计不以单一指标展示为目标，而是构建“静态特征 - 形成机制 - 空间偏好”三位一体分析框架，支撑招聘决策与岗位匹配判断。

---

## 2. 页面信息架构

页面采用“上 - 中 - 下”三层结构。

## 2.1 顶部全局控制层

- 页面标题：`Q2 职位画像分析 · 三主视图排版方案`
- 副标题：说明页面支持三职位并行对比
- 右上工具：分析周期、导出报告
- 统一职位选择栏：最多 3 个职位（职位 A/B/C）
- 操作按钮：同步分析、重置

该层作用是建立统一数据上下文，驱动下方三个主视图同步刷新。

## 2.2 中层三主视图层

按 `左 - 中 - 右` 分栏：

- 左：轮廓对比图（概览）
- 中：路径流向图（解释）
- 右：偏好城市地图（空间）

三者形成“是什么 - 为什么 - 在哪里”的互补关系。

## 2.3 底部统计与声明层

- 统计卡：分析样本、覆盖行业、覆盖城市、分析维度
- 声明区：强调数据脱敏用途与研究边界

该层用于补充样本规模、覆盖范围与隐私合规语境。

---

## 3. 三主视图设计

## 3.1 轮廓对比图（左）

### 设计意图

用于快速比较多个职位在关键维度上的相对强弱，建立首屏认知。

### 视觉形式

- 头像卡 + 星级评分矩阵
- 列表示职位（A/B/C）
- 行表示维度

### 维度集合（6维）

1. 薪资水平
2. 技能要求
3. 行业集中度
4. 城市分布广度
5. 成长空间
6. 稳定性

### 视觉编码

- 颜色：A 蓝、B 红、C 绿
- 星级数量：维度得分高低（相对表现）

### 价值

较雷达图更易首屏阅读，适合“快速感知差异”场景。

## 3.2 路径流向图（中）

### 设计意图

解释岗位画像背后的形成机制，回答薪资结果如何产生。

### 视觉形式

- 桑基图（左到右）
- 路径链路：
  `技能水平 -> 行业分布 -> 市场需求 -> 薪资水平`

### 分层状态

- 技能水平：高/中/低
- 行业分布：分散/中等/集中
- 市场需求：高/中/低
- 薪资水平：高/中/低

### 视觉编码

- 节点面积：该状态占比
- 连线宽度：路径流量占比
- 分层颜色：维持状态分层可读性

### 价值

从“描述型画像”升级为“解释型画像”，支撑机制分析与论证。

## 3.3 偏好城市地图（右）

### 设计意图

展示不同职位在空间维度的偏好重心与竞争关系。

### 视觉形式

- 中国底图 + 饼图气泡
- 气泡标签使用匿名城市编码（例如 C25/H08/B09）

### 隐私策略

由于原始城市字段为脱敏编码：

- 不展示真实城市名
- 保留中国空间框架
- 采用匿名编码标注与映射

### 视觉编码

- 位置：匿名城市对应点位
- 气泡大小：综合偏好量级
- 饼图扇区：A/B/C 三职位占比

### 价值

实现“保留空间认知 + 保护敏感信息”的平衡表达。

---

## 4. 设计优势总结

1. 三主视图职责清晰，不重复
2. 全页面围绕“三职位对比”构建，语义一致
3. 在脱敏约束下仍保留地理分析能力
4. 信息层级明确，阅读路径自然

一句话概括：

该页面是一个面向三职位并行对比的总览仪表盘，以轮廓对比、路径解释与空间偏好三视角协同构建完整、可解释且合规的 Q2 职位画像分析界面。
