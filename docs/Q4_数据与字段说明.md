# Q4 地域数据分析：现有数据与字段说明

Q4 当前实现包含：城市等级热力图、城市词云、地域相似性、行业区位气泡。

## 1. Q4 当前可用接口

- `GET /api/charts/heatmap/city-tier?tier=...&dimension_y=company_type&metric=...`
  - 城市等级矩形热力图
- `GET /api/charts/wordcloud/city?city=...&top_n=...`
  - 城市词云
- `GET /api/charts/region/profile?city=...&top_similar=...`
  - 城市画像与相似城市
- `GET /api/charts/bubble/industry-location?city_tiers=...&industry_filter=...`
  - 全国规模 × 区位商 × 城市等级 气泡图

对应代码：`routes/heatmap_routes.py`、`routes/wordcloud_routes.py`、`routes/region_profile_routes.py`、`routes/industry_bubble_routes.py`

---

## 2. Q4 关键数据表

## 2.1 `city_type_statistics_top20`（热力图主表）

| 字段 | 类型 | 含义 | Q4 用途 |
|---|---|---|---|
| `city` | varchar | 城市编码 | X轴 |
| `city_tier` | varchar | 城市等级（中文：一线/二线/三线/其他） | 过滤条件 |
| `company_type` | varchar | 公司类型编码 | Y轴 |
| `job_count` | int | 职位数 | metric=job_count |
| `industry_ratio` | double | 该类型在城市内占比 | metric=industry_ratio |
| `location_quotient` | double | 区位商 | metric=location_quotient |
| `total_jobs_in_city` | int | 城市岗位总量 | 详情 |
| `company_count_in_city` | int | 城市公司总数 | 详情 |
| `national_job_count` | int | 全国该类型岗位总数 | 详情 |
| `avg_education_rank` / `avg_experience_rank` | double | 教育/经验均值 | 详情 |
| `is_in_ten` | int | 是否Top类别标记 | 可视强调 |

## 2.2 `city_type_statistics`（气泡图主表）

与 top20 表字段相近，但不做前20截断，适合全量气泡分析。

## 2.3 其他来源

- 词云：`dataset/dataset/第四题/city_wordcloud_data.json`
- 相似城市：`services/region_profile_service.py`（基于数据构建城市画像向量）

## 3. 热力图接口返回结构（核心）

- `tier` / `tier_name` / `city_count`
- `dimensions.x_axis`（城市）
- `dimensions.y_axis`（公司类型）
- `heatmap_data[]`：
  - `x`, `y`, `value`, `count`
  - `detail_info.industry_ratio`
  - `detail_info.location_quotient`
  - `detail_info.avg_education_rank`
  - `detail_info.avg_experience_rank`
  - `detail_info.company_count_in_city`
  - `detail_info.national_job_count`

---

## 4. 行业区位气泡接口返回结构（核心）

- `national_total_jobs`
- `bubble_data[]`：
  - `city`, `city_tier`, `industry_label`
  - `national_job_count`, `national_job_percentage`
  - `location_quotient`
  - `local_job_count`, `city_total_jobs`, `industry_ratio`
  - `avg_education_rank`, `avg_experience_rank`
  - `is_in_ten`, `is_highlight`（可选）
- `industry_list[]`, `city_tier_list[]`

---

## 5. Q4 设计建议

- 如果要“宏观格局”优先：热力图 + 区位气泡；
- 如果要“单城故事”优先：城市卡片 + 词云 + 相似城市；
- 城市字段是编码值时，建议补编码到中文名映射，提升可读性。
