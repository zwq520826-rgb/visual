# Q3 薪资多维分析：现有数据与字段说明

Q3 对应当前项目里的三维薪资相关接口，核心是经验-学历-薪资的多维关系。

## 1. Q3 当前可用接口

- `GET /api/charts/3d/experience-education-salary`
  - 经验 × 学历 × 平均薪资三维数据
- `GET /api/charts/boxplot/salary-distribution?experience=...&education=...&city=...&company_type=...`
  - 在指定经验和学历下，按城市/公司类型给薪资箱线统计
- `GET /api/charts/radar-bubble`
  - 经验分层的城市气泡统计（含香农熵）
- `GET /api/charts/parallel-coordinates`
  - 城市/经验/学历/行业/薪资/熵/数量的平行坐标源数据

对应代码：`routes/salary_3d_routes.py`、`services/salary_3d_service.py`、`services/radar_bubble_service.py`

---

## 2. Q3 关键数据表

## 2.1 `data`（原始明细主表）

| 字段 | 类型 | 含义 |
|---|---|---|
| `job_title` | varchar | 职位 |
| `city` | varchar | 城市编码 |
| `salary` | varchar | 原始薪资区间字符串 |
| `min_annual_salary` / `max_annual_salary` / `median_annual_salary` | double | 年薪统计值 |
| `experience` | varchar | 经验编码 |
| `education` | varchar | 学历编码 |
| `experience_rank` / `education_rank` | bigint | 经验/学历等级分值 |
| `company_type` | varchar | 行业/公司类型编码 |
| `job_in_city_cnt` | bigint | 职位在该城市岗位数 |
| `job_in_industry` | bigint | 职位在行业内规模 |
| `shannon_entropy` | double | 岗位分布熵 |

## 2.2 映射表

- `experience_mapping(experience_code, experience_label)`
- `education_mapping(education_code, education_label)`

用途：把编码转换为中文等级标签，便于 Q3 轴标签与 tooltip 展示。

## 3. 各接口字段结构

## 3.1 三维柱状图 `/charts/3d/experience-education-salary`

- `experiences`: 经验标签数组（已按逻辑顺序排序）
- `educations`: 学历标签数组（已按逻辑顺序排序）
- `data_3d`: `[expIndex, eduIndex, avg_salary]`
- `data_detail[]`:
  - `experience`
  - `education`
  - `avg_salary`
  - `job_count`

## 3.2 箱线图 `/charts/boxplot/salary-distribution`

- 输入：`experience`、`education` 必填；`city`、`company_type` 可选
- 输出：
  - `city_data[]`：按城市聚合的 `stats(min/q1/median/q3/max/count)`
  - `company_type_data[]`：按行业聚合的同结构统计
  - `cities[]`、`company_types[]`

## 3.3 雷达气泡 `/charts/radar-bubble`

- `experiences[]`
- `data[]` 每项包含：
  - `experience`
  - `cities[]`（每个城市含 `job_count`、`avg_salary`、`shannon_entropy`、`job_titles`）
  - `total_cities`、`total_jobs`

## 3.4 平行坐标 `/charts/parallel-coordinates`

- `data[]` 每项字段：
  - `city`
  - `experience`
  - `education`
  - `company_type`
  - `salary`
  - `entropy`
  - `job_count`

---

## 4. Q3 设计建议

- 若强调“结构关系”，优先 3D + parallel；
- 若强调“分布与异常值”，优先 boxplot；
- 若强调“城市异质性”，优先 radar-bubble（含熵值维度）。
