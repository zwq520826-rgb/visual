# Q5 行业发展动态与新兴职位识别 - 视图设计方案

## 设计概述

Q5 作为综合分析层，需要在 Q1-Q4 的多维分析基础上，提炼出**行业发展趋势**和**新兴职位特征**两个核心洞察。设计采用**三视图联动**的方式，从宏观→中观→微观三个层级递进分析。

---

## 视图设计方案

### **视图1：行业发展动态多维雷达图** 
**（Industry Development Radar Chart）**

#### 视觉形式
- **类型**：多边形雷达图（Radar/Radial Chart）
- **展示方式**：不同行业用不同颜色的多边形线条表示，可同时展示3-5个核心行业对比

#### 核心维度（6个）
基于 `national_industry_stats` 表，标准化为 0-100 分：

| 维度 | 数据源字段 | 含义 | 业务价值 |
|---|---|---|---|
| 📊 **市场规模** | `job_count` | 行业岗位总数 | 反映产业活跃度与投资热度 |
| 💰 **薪资水平** | `avg_median_salary` | 行业平均中位薪资 | 反映行业经济价值与竞争力 |
| 🎓 **教育水平** | `avg_education_rank` | 平均学历要求 | 反映专业技术深度 |
| 📈 **经验要求** | `avg_experience_rank` | 平均工作年限需求 | 反映行业复杂度与成熟度 |
| 🌍 **地域覆盖** | `city_count` | 覆盖城市数量 | 反映行业的发展广度与机会分布 |
| 🔄 **职位多样性** | `job_type_count` | 职位类型数量 | 反映细分化程度与生态完整性 |

#### 交互设计
- **鼠标悬停**：显示具体数值
- **行业切换**：可选择不同行业进行对比（建议 Top 5 行业）
- **维度筛选**：支持关闭某个维度便于对比

#### 设计意义
- 快速对比行业的综合发展状况
- 识别"全面领先"的高增长行业
- 发现传统行业的"升级空间"

#### 关键发现示例
```
高科技行业（云计算、AI）：6维度均在80分以上 → 全面领先
传统制造业：市场规模高，但教育/经验/薪资均低 → 面临升级
```

### **视图2：新兴职位识别散点图**
**（Emerging Job Identification Bubble Chart）**

#### 视觉形式
- **类型**：交互式气泡散点图（Bubble Scatter Chart）
- **布局**：二维平面 + 气泡大小 + 颜色编码

#### 三维编码方案

| 编码维度 | 数据源 | 含义 |
|---|---|---|
| **X 轴** | `median_salary`（Q2/Q3数据） | 平均薪资（万元/年） → **经济价值** |
| **Y 轴** | **稀缺度指数** | 人才供给紧张程度（0-100） → **机会稀缺性** |
| **气泡大小** | `records_count_norm`（Q1数据） | 岗位热度/市场需求量 → **市场规模** |
| **气泡颜色** | `company_type`（Q4数据） | 行业分类 → **产业归属** |

#### 人才稀缺度指数计算逻辑
```
稀缺度 = (教育要求 + 经验要求) × 0.7 + (1 - 供给占比) × 0.3

高稀缺性 = 高技能要求 + 相对供给不足
```

#### 象限含义
```
        高稀缺度
            ↑
            │  
  高端冷门  │  ⭐ 高端热门（新兴职位核心）
  (小众)    │      高薪+稀缺+需求旺
            │
    ────────┼────────→ 高薪资
            │
  普遍热门  │  普遍冷门
  (大众)    │  (衰退)
            
        低稀缺度
```

#### 新兴职位标记规则
满足以下条件的职位用**红色星标（★）**突出显示：
1. 稀缺度指数 > 75 分位（人才缺口明显）
2. 薪资 > 中位数（经济吸引力）
3. 岗位总数 > 100（市场规模足够）

#### 交互设计
- **悬浮提示**：显示职位名称、岗位数、薪资、稀缺度指数
- **点击职位**：展开该职位的详细画像（链接到Q2数据）
- **行业筛选**：支持按行业着色或单独显示

#### 设计意义
- 清晰识别"薪资高+稀缺+需求旺盛"的新兴职位  
- 对比新兴职位与普遍职位的特征差异
- 为求职者与企业提供决策参考

#### 关键发现示例
```
新兴职位集中在右上象限：
  - 云计算架构师：薪资28万 | 稀缺度82 | 岗位450个 ★
  - AI工程师：薪资26万 | 稀缺度79 | 岗位380个 ★
  - 数据安全专家：薪资25万 | 稀缺度75 | 岗位320个 ★

共同特征：高技能要求 + 供给缺口 + 市场需求旺
```

### **视图3：行业-新兴职位关联图**
**（Industry-Emerging Job Relationship Diagram）**

#### 视觉形式
- **类型**：Sankey 流向图 或 Sunburst 旭日图
- **结构**：三层级递进展示

#### 结构设计（以Sankey为例）

```
第一层：全国招聘总体（430k 招聘记录）
         ↓↓↓
第二层：行业分类（158个行业，按规模排序）
  ├─ 云计算和IDC服务 (3450职位)
  ├─ 互联网/电商 (5600职位)
  ├─ 人工智能 (2100职位)
  ├─ 金融科技 (1800职位)
  └─ ...其他行业
         ↓↓↓
第三层：各行业的新兴职位 TOP 3（按稀缺度排序）
  云计算 → 【云架构师】450个岗位
  云计算 → 【数据库SRE】320个岗位
  云计算 → 【安全工程师】280个岗位
  AI → 【ML工程师】420个岗位
  ...
```

#### 视觉编码
- **流向宽度** = 该职位的岗位数量（宽度越大需求越大）
- **颜色** = 行业分类（保持与视图1、视图2的一致性）
- **流向亮度** = 稀缺度指数强度（越亮越稀缺）

#### 交互设计
- **悬浮流向**：显示职位名称、岗位数、所属行业、稀缺度等信息
- **单击行业**：展开或折叠该行业的新兴职位列表
- **动画流向**：用动画效果展示应聘流向强度

#### 设计意义
- 清晰展示新兴职位的产业分布
- 理解行业升级与新兴职位的关系
- 识别"传统行业的数字化转型岗位"

#### 关键发现示例
```
高科技行业（云计算、AI）：直接创造新兴职位
  └─ 占新兴职位总数的 58%
  
传统行业的转型机会：衍生新兴职位
  └─ 制造业的"数字化转型官"、金融的"科技官"等
  └─ 占新兴职位总数的 31%
  
其他机会：新交叉领域
  └─ 占新兴职位总数的 11%
```

## 三视图联动设计原则

### 1️⃣ **视觉一致性**
- 行业配色统一：云计算(蓝)、AI(紫)、互联网(绿)、金融(金黄)、制造(灰)
- 相同概念的颜色/形状在三图中保持一致

### 2️⃣ **信息递进性**
```
视图1 → 行业宏观格局       "哪些行业在增长？"
视图2 → 职位机会识别       "哪些职位值得关注？"
视图3 → 产业链升级         "新职位与产业的关系？"
```

### 3️⃣ **交互联动性**
- 点击视图1中的行业 → 视图2过滤该行业职位
- 悬浮视图2的职位 → 视图3高亮该职位所属行业
- 选中视图3的职位 → 链接到Q2职位画像详情

## 数据支撑与计算

### 数据来源
| 视图 | 主要数据表 | 辅助表 |
|---|---|---|
| 视图1 | `national_industry_stats` | `experience_mapping`, `education_mapping` |
| 视图2 | `job_summary` + 衍生指标 | `job_summary_by_title`, `cluster_by_city` |
| 视图3 | `job_summary` + 视图2结果 | `national_industry_stats` |

### 关键指标
- **稀缺度指数**：基于教育/经验要求与供给占比的综合计算
- **新兴职位**：稀缺度>75分位 AND 薪资>中位数 AND 岗位>100
- **行业活力**：市场规模×薪资×多样性的综合评分

---

## 设计优势

✅ **层次清晰**：从宏观(行业) → 中观(职位) → 微观(产业链)  
✅ **数据充分**：充分利用Q1-Q4各维度数据  
✅ **商业价值**：既展示行业趋势，也发现具体机会  
✅ **可交互性**：支持深度探索与下钻分析  
✅ **易理解**：配色/形状/编码方式直观明快

## 预期演讲框架（≤500字）

**Q5 核心发现**：

基于市场规模、薪资、人才要求等6个维度的行业分析，以及职位稀缺度指数的创新定义，我们发现：

**第一：行业分化加剧**
- 高科技行业（云计算、AI、大数据）在6个维度全面领先，活力指数>85
- 传统行业虽保有市场规模，但薪资、教育要求、职位多样性明显滞后
- 新兴行业增长快，但成熟度还需提升

**第二：新兴职位(42个)突出特征**
- 高技能密集：本科+占比92%，硕士+占比24%
- 供给缺口：稀缺度指数>75，市场供给明显不足
- 经济吸引力强：平均薪资26万元/年，高于全国平均35%
- 典型代表：云计算架构师、AI工程师、数据安全专家

**第三：产业链升级路径**
- 高科技行业直接创造新兴职位（58%）
- 传统行业转型方向衍生新兴职位（31%）：如制造业的数字化转型岗位、金融的科技官
- 跨界融合职位持续涌现（11%）

**启示**：
- 求职者应关注新兴职位，快速晋升空间大
- 企业应加大新兴职位的招聘投入与薪酬竞争力
- 教育机构需对标新兴职位调整课程设置
- 政策制定部门可据此指导产业升级方向
