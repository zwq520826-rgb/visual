# 可视化修改说明（数据大屏风）

## 修改目标
- 将项目视觉风格从浅色学术卡片风，升级为数据大屏风。
- 保持原有数据接口与图表逻辑不变，主要修改图表呈现、页面氛围和交互视觉反馈。

## 已修改文件
- `fronted/src/App.vue`
- `fronted/src/components/Dashboard.vue`
- `fronted/src/components/tabs/Q1Tab.vue`
- `fronted/src/components/charts/ScatterBubbleChart.vue`
- `fronted/src/config/appConfig.js`

## 具体修改内容

### 1) 全局背景升级（App）
- 修改 `fronted/src/App.vue`。
- 使用深色渐变 + 多层径向光晕 + 青蓝网格，形成大屏氛围底图。
- 弱化原暖色背景，统一为冷色科技感风格。

### 2) 顶部导航与容器风格升级（Dashboard）
- 修改 `fronted/src/components/Dashboard.vue`。
- 顶部导航改为深色半透明玻璃态，增加青蓝边线与阴影。
- 标签栏改为高对比霓虹风：
  - 未激活：浅蓝文字
  - 激活态：蓝青渐变高亮块
  - Hover：亮色反馈增强
- 主内容容器改为深色玻璃卡片，边框和阴影改为大屏视觉语言。

### 3) Q1 页面结构视觉强化
- 修改 `fronted/src/components/tabs/Q1Tab.vue`。
- 标题与说明文字改为浅蓝文本，提升深色背景可读性。
- 右侧两张联动图增加深色面板、发光边框和圆角，强化模块分区。
- 分割线由浅灰改为青蓝半透明线，视觉更统一。

### 4) Q1 散点气泡图主题重绘
- 修改 `fronted/src/components/charts/ScatterBubbleChart.vue`。
- 控件区（城市选择、模式切换、图例）整体改为深色面板样式。
- 按钮与选择框加入高亮边框、激活渐变、悬停色反馈。
- 图表配色升级：
  - 职位层级颜色改为蓝/青/亮蓝/金色
  - 行业颜色池改为统一冷色高亮序列
- ECharts 坐标轴与网格线改为浅蓝系，提升大屏观感与对比。
- 图表背景改为深色透明层，标题文字改为浅蓝高可读样式。
- 工具箱图标颜色改为青蓝系，保持交互一致性。

### 5) Q1 图表能力升级（不仅风格）
- 修改 `fronted/src/components/charts/ScatterBubbleChart.vue`。
- 新增多指标映射控制：
  - X轴可切换（如经验/薪资/学历/熵等）
  - Y轴可切换
  - 气泡大小可切换（招聘人数/薪资波动等）
- 新增 `Top标注` 开关：自动标记当前视图下 Y 值最高的前 8 个点。
- 新增 `趋势线` 开关：基于当前散点自动绘制平滑趋势线，辅助解释整体走向。
- 坐标范围从固定值改为按数据自动伸缩，避免不同数据下图形挤压。
- 气泡大小由固定字段改为动态按所选指标重新归一化。

### 6) Q1 两张右侧图已替换
- 原“职位多维对比（雷达图）”替换为 `极坐标柱状图（Polar Bar / Nightingale 风格）`。
  - 文件：`fronted/src/components/charts/PolarComparisonChart.vue`
  - 特点：维度按角度排布，强度按半径展示，支持 2-3 个职位透明叠加比较。
- 原“职位差异度分析（环形差异图）”替换为 `蝴蝶图 / 发散型柱状图（Butterfly / Diverging Bar）`。
  - 文件：`fronted/src/components/charts/ButterflyDifferenceChart.vue`
  - 特点：中轴为维度，左侧职位A、右侧职位B，适合 1v1 PK 场景。
- Q1 容器已改为挂载新组件：
  - `fronted/src/components/tabs/Q1Tab.vue`
  - `RadarComparisonChart` -> `PolarComparisonChart`
  - `DifferenceRingChart` -> `ButterflyDifferenceChart`

### 7) Q1 行业模式两张图已替换
- 原“行业差异分布条”替换为 `差异矩阵热力图（Difference Heatmap）`。
  - 文件：`fronted/src/components/charts/IndustryDifferenceHeatmap.vue`
  - 设计：X轴为维度，Y轴为行业，颜色表示偏离均值程度（z-score）。
- 原“行业差异力引导图”替换为 `RadViz（径向坐标）`。
  - 文件：`fronted/src/components/charts/IndustryRadVizChart.vue`
  - 设计：圆周为维度锚点，内部散点为行业，位置由多维“引力平衡”决定。
- Q1 行业模式容器改为挂载新组件：
  - `fronted/src/components/tabs/Q1Tab.vue`
  - `IndustryDifferenceBarChart` -> `IndustryDifferenceHeatmap`
  - `ForceDirectedChart` -> `IndustryRadVizChart`

### 8) 主题配置统一
- 修改 `fronted/src/config/appConfig.js`。
- 主题主色、辅色与背景配置由紫色系改为蓝青系。

## 修改效果（预期）
- 打开页面时，整体观感更像“展示型数据大屏”。
- Q1 图表主体与控制区层级更清晰，视觉焦点更集中。
- 深色背景下信息对比更强，适合投屏与答辩展示。
- 图表表达能力更强：同一批数据可快速切换不同分析视角，不再只是固定散点展示。

## 备注
- 本次未改动后端接口与数据库结构。
- 本次未改动后端接口，前端图表能力增强基于现有数据字段完成。
