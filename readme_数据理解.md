## 3. 每个文件的用途

- `表2_2_数据规模.csv`
  - 用于章节背景、规模核对、总量口径统一。

- `表2_3_字段说明_完整版.csv`
  - 用于字段字典（含义、示例、类型、说明、分析用途）。

- `表2_6_薪资格式分布.csv`
  - 用于薪资清洗规则优先级设计（先处理月薪区间，再处理时薪/日薪/周薪）。

- `表2_6_薪资区间分布_5K分箱.csv`
  - 用于薪资分布可视化基线（0~5K步长，40K+合并）。

- `表2_7_经验维度_全量.csv` 与 `表2_7_学历维度_全量.csv`
  - 用于门槛变量排序和门槛指数构建前的探索。

- `表2_8_职位维度_全量.csv`
  - 用于职位差异、职位画像、职位聚类的输入基表。

- `表2_9_城市维度_全量.csv`
  - 用于地域画像、城市分群、城市相似度分析。

- `表2_10_行业维度_全量.csv`
  - 用于行业规模、行业薪资、行业结构与潜力分析。

## 4. 第三章衔接建议

- 建议以当前脚本逻辑为统一口径继续清洗，不要每个人从原始 `JobWanted.xlsx` 独立重跑。
- 若需新增清洗规则，请在同一脚本链路中追加，避免字段口径漂移。
- 原始数据文件 `dataset/JobWanted.xlsx` 仅用于追溯与抽样校验。

## 5. 口径提醒

- 当前薪资统计中的“有效月薪”来自可解析记录。
- 时薪/日薪/周薪在第二章只做识别统计，统一换算建议在第三章执行。
- 编码字段（职位/城市/行业/经验/学历）均为匿名编码，解释依赖统计关联。
